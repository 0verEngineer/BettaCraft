# Rotflossen-Antennenwels

![Rotflossen-Antennenwels](../images/tm_redtail_catfish.png)

Ein schwerer Wels mit sehr breitem, flachem Kopf, langen Barteln an den Ecken des breiten Mauls, dunkelgrauem Rücken,
cremeweißem Band an der Flanke und leuchtend roter Schwanzflosse. In großen Schauaquarien wird er etwa 1,2 Meter lang
(wild bis 1,8 m).

**Herkunft:** Amazonas und Orinoko.

## Steckbrief

| | |
|---|---|
| Gruppe | Welse |
| Wissenschaftlicher Name | *Phractocephalus hemioliopterus* |
| Größe | etwa 1,2 m (2,4 Blöcke im Spiel) |
| Becken | mindestens 15 × 8 Blöcke, 4 hoch, je 173 Wasserblöcke |
| Temperatur | 20–28 °C |
| Wasser | Süßwasser, robust |
| Wasserchemie | pH 5,5–7,8, TDS 0–500 ppm |
| Schwarm | einzeln oder als Paar |
| Schwimmt | im unteren Wasser |
| Besatz | zählt als 43,2 Fisch |
| Zucht | vermehrt sich nicht im Aquarium |
| Betta-Becken | nein (frisst sie) |
| Besonderheiten | frisst kleine Fische, Bettas und Garnelen, schwimmt weite Bögen, nachtaktiv |

## Haltung

* Ein großes Tier: es braucht ein Becken von mindestens 15 × 8 Blöcken und 4 Blöcken Höhe und 173 eigene Wasserblöcke
  ([Größenregel](../big_tanks.md)).
* Tagsüber ruht er viel am Boden, in der Dämmerung und nachts jagt er; lass ihm eine freie Bodenfläche.
* Ein Räuber, der alles verschluckt, was in sein Maul passt: kleine Fische, Bettas, Garnelen. Halte ihn allein oder mit
  anderen Riesen.
* Weiches bis mittelhartes, warmes Wasser (20–28 °C). Er vermehrt sich nicht im Becken.

## Bezug

* **[Großer Kescher](large_net.md)** in Dschungelgewässern: 1,1 % pro Schwung (etwa 1 von 88 Schwüngen), in eine leere Transportwanne (Config `features.bigAnimals`).
* **[Stahlvorfach](steel_leader.md)** (Angeln) in Dschungelgewässern: 1,4 % pro Fang (etwa 1 von 70 Fängen), in eine leere Transportwanne (Config `features.bigAnimals`).
* **Wild** in Dschungelgewässern, einzeln (Spawn-Gewicht 2) (Config `features.bigAnimals`).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
