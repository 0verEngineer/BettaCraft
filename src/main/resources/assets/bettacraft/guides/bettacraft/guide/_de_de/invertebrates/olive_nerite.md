# Oliv-Rennschnecke

![Oliv-Rennschnecke](../images/sp_olive_nerite.png)

Die Olivgrüne Rennschnecke (*Neritina reclivata*) von den Küsten Floridas und der Karibik: ein glattes olivgrünes Gehäuse.

## Steckbrief

| | |
|---|---|
| Gruppe | Schnecken |
| Größe im Spiel | etwa 2 cm (0,18 Blöcke) |
| Temperatur | 20–28 °C |
| Wasser | Süß-, Brack- oder Meerwasser, normal |
| Vermehrung | keine Jungen im Süßwasser |
| Algen | weidet 2 Scheiben am Tag ab |
| Klettert an der Scheibe | ja |
| Besatz | 50 zählen als ein Fisch |

## Haltung

* Eine gute Algenfresserin.
* Vermehrt sich im Süßwasser nie.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Mangrovensümpfen: 9–11 % pro Schwung, 1–2 auf einmal.
* **[Kescher](../equipment/tank_net.md)** an Stränden: 9–11 % pro Schwung, 1–2 auf einmal.
