# Rote Wurzelflosse

![Rote Wurzelflosse](../images/sp_red_root_floater.png)

Rote Wurzelflosse (*Phyllanthus fluitans*) aus Südamerika: runde Blätter und rote Wurzeln, rot bei viel Licht und grün bei wenig Licht.

## Steckbrief

| | |
|---|---|
| Wuchsform | Schwimmpflanze |
| Blattgröße | bis 4,8 cm |
| Wachstum | mittel |
| Nimmt Abfall auf | ×1,2 |
| Nestplatz | gut |
| Wurzeln | lang |

## Haltung

* Langsam; ihre Farbe zeigt, wie stark das Licht ist.
* Selten: beim Angeln in Mangrovensümpfen oder beim fahrenden Händler.

## Bezug

* **Angeln** in Mangrovensümpfen: 0,75 % pro Fang (etwa 1 von 133 Fängen), statt des Fischs.
* **Fahrender Händler** (seltene Angebote): 2 für 3 Smaragde.
* **Ableger**: wächst auf einer beleuchteten Wasseroberfläche und bildet Ableger; mit dem Kescher herausnehmen.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
