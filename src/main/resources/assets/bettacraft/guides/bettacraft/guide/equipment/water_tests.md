# TDS meter and pH drop test

Two tools to measure the [water chemistry](../aquarium/water_chemistry.md) at the aquarium (right-click a tank
block; the tank menu shows the same values in the tab **Water**):

* <ItemLink id="bettacraft:tds_meter" />: the TDS in ppm and the hardness (soft, medium hard, hard). It never wears
  out.
* <ItemLink id="bettacraft:ph_test_kit" />: the pH, whether it is acidic, neutral or alkaline, and where it is drifting
  (for example "falling to 6.4" on a fresh soil floor). Each test uses a drop: enough for 50 tests.
