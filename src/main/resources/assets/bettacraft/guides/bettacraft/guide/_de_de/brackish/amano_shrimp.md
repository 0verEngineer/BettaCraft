# Amano-Garnele

![Amano-Garnelen und eine Wolke ihrer Larven](../images/sp_amano_shrimp.png)

Die Amano-Garnele (*Caridina multidentata*, etwa 5 cm) aus den Küstenflüssen Japans und Taiwans: grau und durchscheinend mit
einer gepunkteten Linie an der Seite, der **stärkste Algenfresser** unter den Zwerggarnelen.

## Steckbrief

| | |
|---|---|
| Gruppe | Garnelen |
| Größe im Spiel | etwa 5 cm (0,42 Blöcke) |
| Temperatur | 18–28 °C |
| Wasser | Süß- oder Brackwasser, empfindlich |
| Wasserchemie | pH 6,5–8,2, TDS 50–600 ppm |
| Vermehrung | Männchen und Weibchen; das Weibchen trägt die Eier, die Jungen schlüpfen fertig entwickelt, 8–18 Junge |
| Heranwachsen | etwa 6 Tage |
| Algen | weidet 0,5 Scheiben am Tag ab |
| Klettert an der Scheibe | ja |
| Besatz | 25 zählen als ein Fisch |

## Zucht mit Brackwasser-Larven

In der Natur paaren sich die Amanos in den Flüssen, und ihre Larven treiben ins Meer. Im Spiel:

1. Die Garnelen paaren sich im **Süßwasser** (nicht im Brackwasser); das Weibchen trägt seine Eier 3 Tage.
2. Dann lässt es eine **Larvenwolke** frei (8–18; winzige helle Pünktchen im Wasser). Im Süßwasser sterben sie nach einem Tag
   (`brackish.amanoFreshLarvaDays`).
3. Mit dem [Kescher](../equipment/tank_net.md) auf die Wolke zielen, eine **leere Fischtüte** im Inventar: Die Larven kommen in
   die Tüte. Mit der Tüte auf ein **Brackwasserbecken** klicken (2 ‰ oder mehr, Meerwasser geht auch), um sie freizulassen.
4. Nach **3 Tagen** (`brackish.amanoLarvaDays`) lässt sich ein Teil als junge Garnelen nieder: 35 % von allein
   (`brackish.amanoLarvaSurvival`), doppelt so viele mit [Phytoplankton](../food/plankton.md) im Wasser (höchstens 80 %).
5. Die Jungen zurück ins Süßwasser setzen: Dort wachsen sie auf und vermehren sich wieder.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Mangrovensümpfen: 2,8–4,7 % pro Schwung (etwa 1 von 21–35 Schwüngen), 1–3 auf einmal (Config `features.brackish.amanoShrimp`).
* **Wild** in Mangrovensümpfen, in Gruppen von 2–5 (Spawn-Gewicht 1) (Config `features.brackish.amanoShrimp`).
* **Fahrender Händler** (übliche Angebote): 3 für 5 Smaragde.
* **Vermehrung** im Aquarium (Männchen und Weibchen).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
