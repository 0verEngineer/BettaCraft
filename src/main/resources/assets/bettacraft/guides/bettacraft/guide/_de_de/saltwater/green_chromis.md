# Grünes Schwalbenschwänzchen

![Grünes Schwalbenschwänzchen](../images/sp_green_chromis.png)

Das Grüne Schwalbenschwänzchen (*Chromis viridis*) aus dem Indopazifik: kleine, grünblau schimmernde Riffbarsche, die im Schwarm über verzweigten Korallen stehen.

## Steckbrief

| | |
|---|---|
| Gruppe | Riffbarsche |
| Wissenschaftlicher Name | *Chromis viridis* |
| Größe im Spiel | etwa 4,5 cm (0,38 Blöcke) |
| Temperatur | 24–28 °C |
| Wasser | Meerwasser, normal |
| Schwarm | ab 5 Tieren |
| Schwimmt | in der Mitte |
| Besatz | zählt als 0,5 Fisch |
| Zucht | vermehrt sich nicht im Aquarium |

## Haltung

* Im **Schwarm ab fünf Tieren** halten.
* Schnell und lebhaft: nichts für ein Seepferdchenbecken.
* Es vermehrt sich nicht im Aquarium.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in warmen Ozeanen (Korallenriffe): 2,9–3,5 % pro Schwung, 1–4 auf einmal.
* **[Kescher](../equipment/tank_net.md)** in lauwarmen Ozeanen: 3,8–4,5 % pro Schwung, 1–4 auf einmal.
* **Fahrender Händler** (übliche Angebote): 6 für 4 Smaragde; eins von 4 in diesem Angebot.
