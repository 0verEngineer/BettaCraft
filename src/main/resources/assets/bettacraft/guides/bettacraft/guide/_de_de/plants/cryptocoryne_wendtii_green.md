# Cryptocoryne wendtii (grün)

![Cryptocoryne wendtii (grün)](../images/sp_cryptocoryne_wendtii_green.png)

*Cryptocoryne wendtii* „Grün“ aus Sri Lanka: eine Rosette grüner Blätter an Stielen.

## Steckbrief

| | |
|---|---|
| Wuchsform | Rosettenpflanze |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | wenig |
| Volle Größe | nach etwa 9 Tagen |
| Breitet sich aus | Ausläufer |
| Ableger pro Schnitt | 1 |

## Haltung

* Im Bodengrund; wenig Licht.
* Bildet ausgewachsen Ausläufer.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 0,58–0,69 % pro Schwung (etwa 1 von 144–173 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Sümpfen: 1,1 % pro Fang (etwa 1 von 91 Fängen), statt des Fischs.
* **Angeln** in Mangrovensümpfen: 1,6 % pro Fang (etwa 1 von 61 Fängen), statt des Fischs.
* **Glasflasche** mit Wasser gefüllt in Sümpfen: 1,5 % pro Flasche, zusätzlich zum Wasser.
* **Schere** an einem wilden Pflanzenbestand in Dschungelgewässern: 100 % pro Schnitt (Config `features.wildPlants`).
* **Schere** an einem wilden Pflanzenbestand in Mangrovensümpfen: 100 % pro Schnitt (Config `features.wildPlants`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt; sie breitet sich auch selbst aus (Ausläufer).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
