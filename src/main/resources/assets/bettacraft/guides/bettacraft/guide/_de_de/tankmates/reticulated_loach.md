# Netzschmerle

![Netzschmerle](../images/tm_reticulated_loach.png)

Graucreme mit einem dunklen Netz aus Y-förmigen Binden (Botia lohachata); eine lebhafte Schmerle von etwa 10 cm.

**Herkunft:** die Flüsse Nordindiens, Nepals und Bangladeschs.

## Steckbrief

| | |
|---|---|
| Gruppe | Schmerlen |
| Wissenschaftlicher Name | *Botia lohachata* |
| Größe im Spiel | etwa 9 cm (0,75 Blöcke) |
| Temperatur | 24–30 °C |
| Wasser | Süßwasser, normal |
| Wasserchemie | pH 6,0–8,0, TDS 0–550 ppm |
| Schwarm | ab 5 Tieren |
| Schwimmt | im unteren Wasser |
| Besatz | zählt als 1,5 Fisch |
| Zucht | vermehrt sich nicht im Aquarium |
| Betta-Becken | ja |
| Besonderheiten | frisst Schnecken |

## Zucht

Vermehrt sich im Becken praktisch nie.

## Haltung

* Frisst Schnecken (keine großen Apfelschnecken; `tankmates.behaviour.clownLoachSnailsPerDay`).
* Bodenfisch: bekommt nur einen Teil des sinkenden Futters, solange schnellere Fische da sind - Futtertabletten gehen direkt zu ihm.
* In der Gruppe ab 5; zählt 1,5 Fische.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,36–0,42 % pro Schwung (etwa 1 von 238–281 Schwüngen), 1–4 auf einmal.
* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 0,2–0,24 % pro Schwung (etwa 1 von 423–501 Schwüngen), 1–4 auf einmal.
* **Wild** in Flüssen, in Gruppen von 3–5 (Spawn-Gewicht 2) (Config `features.barbsAndLoaches`).
* **Wild** in Sümpfen, in Gruppen von 3–5 (Spawn-Gewicht 1) (Config `features.barbsAndLoaches`).
* **Fahrender Händler** (seltene Angebote): 6 für 12 Smaragde; eins von 12 in diesem Angebot.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
