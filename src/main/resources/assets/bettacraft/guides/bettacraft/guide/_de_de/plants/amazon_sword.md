# Amazonas-Schwertpflanze

![Amazonas-Schwertpflanze](../images/sp_amazon_sword.png)

Die Amazonas-Schwertpflanze (*Echinodorus grisebachii* „Bleherae“) aus Südamerika: eine große Rosette langer, hellgrüner Blätter.

## Steckbrief

| | |
|---|---|
| Wuchsform | Rosettenpflanze |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | mittel |
| Volle Größe | nach etwa 7 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* Im Bodengrund; mittleres Licht.
* Ein Blickfang für größere Becken.

## Bezug

* **Fahrender Händler** (übliche Angebote): 1 für 1 Smaragd.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt.
