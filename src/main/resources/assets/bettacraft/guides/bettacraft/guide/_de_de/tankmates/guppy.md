# Guppy

![Guppy](../images/tm_guppy.png)

Männchen mit großen bunten Schwänzen, Weibchen größer und grau. Betta-Männchen gehen auf Guppy-Männchen los.

| | |
|---|---|
| Familie | Lebendgebärende |
| Wissenschaftlich | *Poecilia reticulata* |
| Größe im Spiel | etwa 4 cm (0,33 Blöcke) |
| Herkunft | Venezuela und Trinidad, heute weltweit verwildert |
| Temperatur | 22–28 °C |
| Schwarm | ab 3 Tieren |
| Wasser | robust |
| Besatz | 0,35 Fisch |
| Zucht | lebendgebärend, 23–28 °C |

## Farbformen

Farbformen: Wildform, Rot, Blue Grass, Green Cobra, Tuxedo (Halbschwarz). Die Wildform ist dominant, Zuchtformen sind rezessiv: Erst zwei gleiche Allele zeigen die Farbe (Träger sehen wild aus). Von zwei verschiedenen Zuchtformen zeigt sich die zuerst genannte. Wildfänge tragen manchmal eine Zuchtform verdeckt; das Menü zeigt die Gene im Tooltip.

## Zucht

Bei 23–28 °C wird ein Weibchen mit einem Männchen trächtig und bringt nach 3 Tagen 5–16 fertige Junge zur Welt. Die Erwachsenen fressen Jungfische: Pflanzen verstecken sie, ein **Ablaichkasten** im Becken fängt sie auf.

## Haltung

* Betta-Männchen jagen die Männchen dieser Art (Config `tankmates.behaviour.bettaAggression`).

## Beschaffung

Mit dem [Kescher](../invertebrates/catching.md) in Flüssen und beim fahrenden Händler; danach durch Zucht.
