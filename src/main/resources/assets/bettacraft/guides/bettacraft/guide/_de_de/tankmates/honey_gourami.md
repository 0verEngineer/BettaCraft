# Honigfadenfisch

![Honigfadenfisch](../images/tm_honey_gourami.png)

Der kleinste und ruhigste Gurami: das Männchen honigorange mit dunkel blauschwarzer Kehle und gelber Rückenflosse, das Weibchen beige mit braunem Streifen.

**Herkunft:** Teiche und langsame Flüsse im Nordosten Indiens und in Bangladesch.

## Steckbrief

| | |
|---|---|
| Gruppe | Fadenfische |
| Wissenschaftlicher Name | *Trichogaster chuna* |
| Größe im Spiel | etwa 5 cm (0,4 Blöcke) |
| Temperatur | 22–28 °C |
| Zuchttemperatur | 25–28 °C |
| Wasser | Süßwasser, normal |
| Wasserchemie | pH 6,0–8,0, TDS 0–500 ppm |
| Schwarm | einzeln oder als Paar |
| Schwimmt | nahe der Oberfläche |
| Besatz | zählt als 0,6 Fisch |
| Zucht | baut ein Schaumnest, 20–60 Junge |
| Betta-Becken | ja |
| Besonderheiten | atmet Luft (Labyrinthfisch), 3 Farbformen |

## Farbformen

Farbformen: Wildform, Gold, Rot. Die Wildform ist dominant, Zuchtformen sind rezessiv: Erst zwei gleiche Allele zeigen die Farbe (Träger sehen wild aus). Von zwei verschiedenen Zuchtformen zeigt sich die zuerst genannte. Wildfänge tragen manchmal eine Zuchtform verdeckt; das Menü zeigt die Gene im Tooltip.

## Zucht

Wie ein Betta: Bei 25–28 °C baut das Männchen ein Schaumnest an der Oberfläche (Schwimmpflanzen helfen), das Weibchen laicht 20–60 Eier hinein, danach jagt das Männchen sie weg und bewacht das Nest.

## Haltung

* **Labyrinthfisch:** atmet wie ein Betta Luft an der Oberfläche und kommt deshalb mit stillem, sauerstoffarmem Wasser zurecht.
* Friedlich: Die Männchen kämpfen nicht, und Betta-Männchen lassen ihn meist in Ruhe.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,27–0,32 % pro Schwung (etwa 1 von 317–375 Schwüngen).
* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 0,6–0,71 % pro Schwung (etwa 1 von 141–167 Schwüngen).
* **Wild** in Flüssen, einzeln (Spawn-Gewicht 2) (Config `features.tankmates.gouramis`).
* **Wild** in Sümpfen, einzeln (Spawn-Gewicht 3) (Config `features.tankmates.gouramis`).
* **Fahrender Händler** (übliche Angebote): 2 für 3 Smaragde; eins von 36 in diesem Angebot.
* **[Zucht](breeding.md)**: baut ein Schaumnest.
