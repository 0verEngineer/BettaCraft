# Kirschflecken-Barbe

![Kirschflecken-Barbe](../images/tm_cherry_barb.png)

Eine kleine, ruhige Barbe mit dunklem Längsstreifen: Das Männchen wird kirschrot, das Weibchen bleibt beige.

**Herkunft:** schattige Waldbäche Sri Lankas.

## Steckbrief

| | |
|---|---|
| Gruppe | Barben |
| Wissenschaftlicher Name | *Rohanella titteya* |
| Größe im Spiel | etwa 5 cm (0,4 Blöcke) |
| Temperatur | 22–28 °C |
| Zuchttemperatur | 24–27 °C |
| Wasser | Süßwasser, normal |
| Wasserchemie | pH 6,0–8,0, TDS 0–500 ppm |
| Schwarm | ab 6 Tieren |
| Schwimmt | in der Mitte |
| Besatz | zählt als 0,4 Fisch |
| Zucht | Freilaicher (feinblättrige Pflanzen, Laichmop), 20–50 Junge |
| Betta-Becken | ja |

## Zucht

Bei 24–27 °C streut ein Paar 20–50 Eier in feinfiedrige Pflanzen, Javamoos oder einen **Laichmopp**. Die Eltern und alle anderen Fische fressen die Eier, die sie erreichen; im Laichmopp sind die meisten sicher. Lebendfutter bringt sie schneller in Laichstimmung.

## Haltung

* Friedlich: eine der wenigen Barben, die ins Betta-Becken passen (22–28 °C).

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,24–0,29 % pro Schwung (etwa 1 von 347–411 Schwüngen), 1–4 auf einmal.
* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,26–0,31 % pro Schwung (etwa 1 von 323–383 Schwüngen), 1–4 auf einmal.
* **Wild** in Flüssen, in Gruppen von 3–6 (Spawn-Gewicht 2) (Config `features.tankmates.barbsAndLoaches`).
* **Wild** in Dschungelgewässern, in Gruppen von 3–6 (Spawn-Gewicht 3) (Config `features.tankmates.barbsAndLoaches`).
* **Fahrender Händler** (übliche Angebote): 6 für 4 Smaragde; eins von 37 in diesem Angebot.
* **[Zucht](breeding.md)**: Freilaicher (feinblättrige Pflanzen, Laichmop).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
