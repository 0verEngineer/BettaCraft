# Aponogeton ulvaceus

![Aponogeton ulvaceus](../images/sp_aponogeton_ulvaceus.png)

*Aponogeton ulvaceus* aus Madagaskar: lange, hellgrüne, gewellte Blätter aus einer Knolle.

## Steckbrief

| | |
|---|---|
| Wuchsform | Knolle mit Schwimmblättern |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | mittel |
| Volle Größe | nach etwa 6 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* Mittleres Licht; die Blätter werden lang und biegen sich über.
* Ausgewachsen schiebt sie einen **Blütenstand** mit weißen Blüten an die Oberfläche.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 0,12–0,14 % pro Schwung (etwa 1 von 722–867 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Flüssen: 0,1 % pro Fang (etwa 1 von 1033 Fängen), statt des Fischs.
* **Schere** an einem wilden Pflanzenbestand in Dschungelgewässern: 100 % pro Schnitt (Config `features.wildPlants`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
