# Anubias „White“

![Anubias „White“](../images/sp_anubias_white.png)

*Anubias barteri* „White“, eine Zuchtform mit fast weißen Blättern; die jungen Blätter sind reinweiß.

## Steckbrief

| | |
|---|---|
| Wuchsform | Aufsitzerpflanze (Rhizom) |
| Wächst auf | Stein und Holz (auch Deko) |
| Licht | mittel |
| Volle Größe | nach etwa 30 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* Auf Stein oder Holz; sehr langsam.
* Braucht etwas mehr Licht als die grünen Anubias (mittleres Licht).

## Bezug

* **Angeln** in Dschungelgewässern: 0,07 % pro Fang (etwa 1 von 1350 Fängen), statt des Fischs.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt; ein abgebautes Rhizomstück teilt sie.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
