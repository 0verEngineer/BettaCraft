# Anubias „Pinto“

![Anubias „Pinto“](../images/sp_anubias_pinto.png)

*Anubias barteri* „Pinto“, eine seltene Zuchtform: dunkelgrüne Blätter, weiß marmoriert.

## Steckbrief

| | |
|---|---|
| Wuchsform | Aufsitzerpflanze (Rhizom) |
| Wächst auf | Stein und Holz (auch Deko) |
| Licht | wenig |
| Volle Größe | nach etwa 32 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* Auf Stein oder Holz; sehr langsam. Jedes Blatt hat seine eigene Marmorierung.
* Wenig Licht genügt; selten beim Angeln im Dschungel.

## Bezug

* **Angeln** in Dschungelgewässern: 0,07 % pro Fang (etwa 1 von 1460 Fängen), statt des Fischs.
* **Schere** an einem wilden Pflanzenbestand in Dschungelgewässern: 100 % pro Schnitt (Config `features.aquaticPlants.wildPlants`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt; ein abgebautes Rhizomstück teilt sie.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
