# Hygrophila pinnatifida

![Hygrophila pinnatifida](../images/sp_hygrophila_pinnatifida.png)

*Hygrophila pinnatifida* aus Indien: tief gelappte, olivbraune Blätter. Ihre Wurzeln halten sich auch an Stein und Holz fest.

## Steckbrief

| | |
|---|---|
| Wuchsform | Stängelpflanze |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden), auch Stein und Holz |
| Licht | mittel |
| Volle Größe | nach etwa 5 Tagen |
| Breitet sich aus | Seitentriebe |
| Ableger pro Schnitt | 3 |
| Farbe | röter bei viel Licht |

## Haltung

* Im Bodengrund oder auf Stein und Holz pflanzen (Steine, Wurzeln, Deko).
* Mittleres Licht; bei viel Licht rötlich.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,32–0,38 % pro Schwung (etwa 1 von 260–313 Schwüngen) (Config `features.aquaticPlants.netCatches`).
* **Angeln** in Flüssen: 0,13 % pro Fang (etwa 1 von 775 Fängen), statt des Fischs.
* **Schere** an einem wilden Pflanzenbestand in Dschungelgewässern: 100 % pro Schnitt (Config `features.aquaticPlants.wildPlants`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 3 Ableger pro Schnitt; sie breitet sich auch selbst aus (Seitentriebe).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
