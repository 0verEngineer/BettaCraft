# Lined Seahorse

![Lined Seahorse](../images/sp_lined_seahorse.png)

The lined seahorse (*Hippocampus erectus*) from the western Atlantic, from Nova Scotia to Venezuela: the most common captive-bred seahorse, dark, yellow or orange, up to about 7 cm in the game.

## Profile

| | |
|---|---|
| Group | Seahorses |
| Scientific name | *Hippocampus erectus* |
| Size in the game | about 7.5 cm (0.62 blocks) |
| Temperature | 18–27 °C |
| Breeding temperature | 21–25 °C |
| Water | sea water, also strong brackish water, sensitive |
| Water chemistry | pH 7.8–8.6 |
| Shoal | alone or as a pair |
| Swims | in the lower water |
| Stocking | counts as 1.5 fish |
| Breeding | Brood pouch: the male carries the eggs, 8–20 young |
| Special | 3 colour varieties |

## Care

* Needs **hitching posts** (plants, corals, decoration, seagrass, kelp) and **low flow**.
* Eats only **live food** (artemia nauplii, mosquito larvae), twice a day.
* Likes it a little cooler than the reef fish. The male carries the eggs in his **brood pouch**; see [Seahorses](seahorses.md).

## Obtaining

* **[Aquarium net](../equipment/tank_net.md)** in warm oceans (coral reefs): 0.62–0.74 % per swing (about 1 in 134–160 swings) (config `features.seahorses`).
* **[Aquarium net](../equipment/tank_net.md)** in lukewarm oceans: 1.5–1.8 % per swing (about 1 in 56–67 swings) (config `features.seahorses`).
* **Wild** in warm oceans (coral reefs), in groups of 1–1 (spawn weight 2) (config `features.seahorses`).
* **Wild** in lukewarm oceans, in groups of 1–1 (spawn weight 2) (config `features.seahorses`).
* **Wandering trader** (rare offers): 2 for 7 emeralds; one of 3 in this offer (config `features.seahorses`).
* **[Breeding](seahorses.md)**: Brood pouch: the male carries the eggs.

The biomes of biome mods count too ([biome tags](../settings.md)).
