# Mexikanische Turboschnecke

![Mexikanische Turboschnecke](../images/sp_turbo_snail.png)

Die Mexikanische Turboschnecke (*Turbo fluctuosa*) aus dem Golf von Kalifornien: eine große Schnecke mit geriffeltem Gehäuse, die beste Algenweide eines Riffbeckens.

## Steckbrief

| | |
|---|---|
| Gruppe | Schnecken |
| Größe im Spiel | etwa 3,5 cm (0,3 Blöcke) |
| Temperatur | 22–28 °C |
| Wasser | Meerwasser, empfindlich |
| Wasserchemie | pH 7,8–8,6 |
| Vermehrung | vermehrt sich nicht im Aquarium |
| Algen | weidet 2,5 Scheiben am Tag ab |
| Klettert an der Scheibe | ja |
| Besatz | 50 zählen als ein Fisch |

## Haltung

* Hält Scheiben und Gestein sauber (2,5 Scheiben am Tag).
* Nur Meerwasser; sie vermehrt sich nicht im Aquarium.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in warmen Ozeanen (Korallenriffe): 9,6–12 % pro Schwung (etwa 1 von 8–10 Schwüngen), 1–2 auf einmal.
* **[Kescher](../equipment/tank_net.md)** in lauwarmen Ozeanen: 11–13 % pro Schwung (etwa 1 von 7–9 Schwüngen), 1–2 auf einmal.
* **Wild** in warmen Ozeanen (Korallenriffe), in Gruppen von 2–5 (Spawn-Gewicht 2) (Config `features.wildCritters`).
* **Wild** in lauwarmen Ozeanen, in Gruppen von 2–5 (Spawn-Gewicht 3) (Config `features.wildCritters`).
