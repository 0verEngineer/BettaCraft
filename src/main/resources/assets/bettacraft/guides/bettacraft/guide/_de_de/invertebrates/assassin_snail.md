# Raubschnecke

![Raubschnecke](../images/sp_assassin_snail.png)

Die Raubturmdeckelschnecke (*Clea helena*) aus Südostasien: ein gelb-braun gebändertes Gehäuse; sie jagt andere Schnecken.

## Steckbrief

| | |
|---|---|
| Gruppe | Schnecken |
| Größe im Spiel | etwa 2 cm (0,17 Blöcke) |
| Temperatur | 20–30 °C |
| Wasser | Süßwasser, normal |
| Vermehrung | Männchen und Weibchen, selten ein Junges, 1–1 Junge |
| Heranwachsen | etwa 6 Tage |
| Klettert an der Scheibe | nein |
| Besatz | 50 zählen als ein Fisch |

## Haltung

* **Frisst andere Schnecken** (Rennschnecken nur selten, ihr Gehäuse ist hart): die natürliche Hilfe gegen zu viele Schnecken.
* Vermehrt sich sehr selten, in Paaren.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,73 % pro Schwung (etwa 1 von 137 Schwüngen).
* **[Kescher](../equipment/tank_net.md)** in Mangrovensümpfen: 1,4–1,7 % pro Schwung (etwa 1 von 58–69 Schwüngen).
* **[Kescher](../equipment/tank_net.md)** in tiefem Höhlenwasser: 3,5–4,2 % pro Schwung (etwa 1 von 24–28 Schwüngen).
* **[Kescher](../equipment/tank_net.md)** in üppigen Höhlen: 2,7–2,9 % pro Schwung (etwa 1 von 34–37 Schwüngen).
* **Wild** in Flüssen, in Gruppen von 2–5 (Spawn-Gewicht 1) (Config `features.wildCritters`).
* **Wild** in Mangrovensümpfen, in Gruppen von 2–5 (Spawn-Gewicht 1) (Config `features.wildCritters`).
* **Fahrender Händler** (seltene Angebote): 1 für 4 Smaragde.
* **Vermehrung** im Aquarium (Männchen und Weibchen).
