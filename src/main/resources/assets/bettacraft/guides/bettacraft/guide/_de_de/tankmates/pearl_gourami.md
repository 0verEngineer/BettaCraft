# Mosaikfadenfisch

![Mosaikfadenfisch](../images/tm_pearl_gourami.png)

Ein großer, eleganter Gurami voller perlmuttfarbener Punkte mit einer dunklen Linie von der Schnauze bis zum Schwanz; das Männchen hat eine orangerote Kehle und lange Flossen.

**Herkunft:** die Sümpfe Thailands, Malaysias, Sumatras und Borneos.

## Steckbrief

| | |
|---|---|
| Gruppe | Fadenfische |
| Wissenschaftlicher Name | *Trichopodus leerii* |
| Größe im Spiel | etwa 10 cm (0,85 Blöcke) |
| Temperatur | 24–30 °C |
| Zuchttemperatur | 27–29 °C |
| Wasser | Süßwasser, normal |
| Wasserchemie | pH 6,0–8,0, TDS 0–500 ppm |
| Schwarm | einzeln oder als Paar |
| Schwimmt | nahe der Oberfläche |
| Besatz | zählt als 1,6 Fisch |
| Zucht | baut ein Schaumnest, 30–80 Junge |
| Betta-Becken | nein |
| Besonderheiten | atmet Luft (Labyrinthfisch), revierbildend, wird von Betta-Männchen gejagt |

## Zucht

Wie ein Betta: Bei 27–29 °C baut das Männchen ein Schaumnest an der Oberfläche (Schwimmpflanzen helfen), das Weibchen laicht 30–80 Eier hinein, danach jagt das Männchen sie weg und bewacht das Nest.

## Haltung

* **Labyrinthfisch:** atmet wie ein Betta Luft an der Oberfläche und kommt deshalb mit stillem, sauerstoffarmem Wasser zurecht.
* Als Paar halten: Zwei Männchen kämpfen um Reviere, und Betta-Männchen gehen auf die Männchen los (`tankmates.behaviour.bettaAggression`).

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 0,5–0,59 % pro Schwung (etwa 1 von 169–200 Schwüngen).
* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,13–0,16 % pro Schwung (etwa 1 von 631–748 Schwüngen).
* **Wild** in Sümpfen, einzeln (Spawn-Gewicht 3) (Config `features.tankmates.gouramis`).
* **Wild** in Dschungelgewässern, einzeln (Spawn-Gewicht 2) (Config `features.tankmates.gouramis`).
* **Fahrender Händler** (übliche Angebote): 2 für 5 Smaragde; eins von 36 in diesem Angebot.
* **[Zucht](breeding.md)**: baut ein Schaumnest.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
