# Apfelschnecke

![Apfelschnecke](../images/sp_apple_snail.png)

Die Paradiesschnecke (*Pomacea diffusa*) aus dem Amazonasbecken: eine große Schnecke, im Handel fast immer **gold**, außerdem wildbraun, blau, violett und elfenbein.

## Steckbrief

| | |
|---|---|
| Gruppe | Schnecken |
| Größe im Spiel | etwa 5 cm (0,4 Blöcke) |
| Temperatur | 20–30 °C |
| Wasser | Süßwasser, normal |
| Vermehrung | Männchen und Weibchen; ein rosa Gelege an der Scheibe über der Wasserlinie, 5–10 Junge |
| Heranwachsen | etwa 4 Tage |
| Algen | weidet 1,5 Scheiben am Tag ab |
| Klettert an der Scheibe | ja |
| Besatz | 50 zählen als ein Fisch |
| Farblinien | 4 (aus Wildtieren herausgezüchtet) |

## Haltung

* Das Weibchen legt ein **rosa Gelege über der Wasserlinie** an die Scheibe; dazu braucht es Luft über dem Wasser.
* Nach 3 Tagen schlüpfen 5–10 Junge, außer du nimmst das Gelege mit dem Kescher oder mit **Gelege entfernen** im Menü ab.
* Die Farben werden vererbt (rezessiv); ein Betta zupft ab und zu an ihren Fühlern (nur ein Anblick).

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 17–20 % pro Schwung (etwa 1 von 5–6 Schwüngen).
* **Wild** in Dschungelgewässern, in Gruppen von 2–5 (Spawn-Gewicht 5) (Config `features.wildCritters`).
* **Fahrender Händler** (übliche Angebote): 1 für 3 Smaragde.
* **Vermehrung** im Aquarium (Männchen und Weibchen).
