# Monte Carlo

![Monte Carlo](../images/sp_monte_carlo.png)

Monte Carlo (*Micranthemum tweediei*) aus Argentinien: ein Teppich winziger runder Blätter.

## Steckbrief

| | |
|---|---|
| Wuchsform | Bodendecker |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | sehr viel (LED-Panel oder Hochleistungs-LED) |
| Volle Größe | nach etwa 3 Tagen |
| Breitet sich aus | Ausläufer |
| Ableger pro Schnitt | 2 |

## Haltung

* Bedeckt den Boden mit Ausläufern; braucht viel Licht.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,8–0,96 % pro Schwung (etwa 1 von 104–125 Schwüngen) (Config `features.plantNetCatches`).
* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 0,96–1,2 % pro Schwung (etwa 1 von 87–104 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Flüssen: 0,13 % pro Fang (etwa 1 von 775 Fängen), statt des Fischs.
* **Schere** an einem wilden Pflanzenbestand in Sümpfen: 100 % pro Schnitt (Config `features.wildPlants`).
* **Fahrender Händler** (übliche Angebote): 2 für 1 Smaragd.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 2 Ableger pro Schnitt; sie breitet sich auch selbst aus (Ausläufer).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
