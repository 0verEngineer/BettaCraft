# Lederkoralle

![Lederkoralle](../images/sp_leather_coral.png)

Die Pilzlederkoralle (*Sarcophyton* sp.) aus dem Indopazifik: ein fester Stamm mit einem Hut, auf dem ein wogender Rasen aus Polypen steht.

## Steckbrief

| | |
|---|---|
| Wuchsform | Pilzlederkoralle (Weichkoralle) |
| Wächst auf | Riffgestein, lebendem Gestein |
| Licht | mittel |
| Strömung | mittel |
| Kalzium | nicht nötig (Weichkoralle) |
| Wasser | Meerwasser |
| Volle Größe | nach etwa 10 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* Weichkoralle: mittleres Licht und mittlere Strömung, kein Kalzium.
* Vermehrung über Ableger (Schere).

## Bezug

* **Ableger**: eine Schere an einer gewachsenen Koralle gibt 1 Ableger pro Schnitt.
