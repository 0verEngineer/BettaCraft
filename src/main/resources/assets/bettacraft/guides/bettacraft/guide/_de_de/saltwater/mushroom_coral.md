# Scheibenanemone

![Scheibenanemone](../images/sp_mushroom_coral.png)

Scheibenanemonen (*Discosoma* sp.) aus dem Indopazifik und der Karibik: flache rotrosa Scheiben, die sich langsam heben und senken.

## Steckbrief

| | |
|---|---|
| Wuchsform | Scheiben (Weichkoralle) |
| Wächst auf | Riffgestein, lebendem Gestein |
| Licht | wenig |
| Strömung | sanft |
| Kalzium | nicht nötig (Weichkoralle) |
| Wasser | Meerwasser |
| Volle Größe | nach etwa 8 Tagen |
| Breitet sich aus | über das Gestein |
| Ableger pro Schnitt | 1 |

## Haltung

* Die genügsamste Koralle: wenig Licht, sanfte Strömung.
* Neben den alten Scheiben entstehen neue.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in warmen Ozeanen (Korallenriffe): 0,6–0,72 % pro Schwung (etwa 1 von 139–167 Schwüngen).
* **Schere** an einem wilden Korallenstock in warmen Ozeanen (Korallenriffe): 100 % pro Schnitt (Config `features.wildCorals`).
* **Fahrender Händler** (übliche Angebote): 2 für 4 Smaragde; eins von 4 in diesem Angebot.
* **Ableger**: eine Schere an einer gewachsenen Koralle gibt 1 Ableger pro Schnitt; sie breitet sich auch selbst aus (über das Gestein).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
