# Roter Tigerlotus

![Roter Tigerlotus](../images/sp_red_tiger_lotus.png)

Der Rote Tigerlotus (*Nymphaea zenkeri*) aus Westafrika: eine Knolle mit gefleckten roten Blättern und Schwimmblättern an langen Stielen.

## Steckbrief

| | |
|---|---|
| Wuchsform | Knolle mit Schwimmblättern |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | mittel |
| Volle Größe | nach etwa 6 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |
| Farbe | röter bei viel Licht |

## Haltung

* Im Bodengrund; mittleres Licht, bei viel Licht röter.
* Seine Schwimmblätter beschatten das Wasser darunter etwas.

## Bezug

* **Fahrender Händler** (seltene Angebote): 1 für 4 Smaragde.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt.
