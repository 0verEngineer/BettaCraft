# Große Netzmuräne

![Große Netzmuräne in ihrer Höhle](../images/tm_honeycomb_moray.png)

Eine große Muräne: ein langer, muskulöser Körper ohne Brustflossen, dicht stehende dunkle Flecken in einem schmalen,
hellgelben Netz, ein hoher Kopf mit tiefem Maul und ein Flossensaum, der über den Rücken um den Schwanz läuft. Im Spiel
1,2 m (wild bis 1,8 m).

**Herkunft:** Riffe und Felsküsten des Indopazifiks.

## Steckbrief

| | |
|---|---|
| Gruppe | Muränen |
| Wissenschaftlicher Name | *Gymnothorax favagineus* |
| Größe | etwa 1,2 m (2,4 Blöcke im Spiel) |
| Becken | mindestens 15 × 8 Blöcke, 4 hoch, je 173 Wasserblöcke |
| Temperatur | 24–28 °C |
| Wasser | Meerwasser, robust |
| Wasserchemie | pH 7,8–8,6 |
| Schwarm | einzeln oder als Paar |
| Schwimmt | im unteren Wasser |
| Besatz | zählt als 43,2 Fisch |
| Zucht | vermehrt sich nicht im Aquarium |
| Besonderheiten | frisst kleine Fische, Bettas und Garnelen, lebt in einer Höhle unter der Deko und kommt nachts und zum Fressen heraus, nachtaktiv |

## Haltung

* Ein großes Tier für das **Meerwasserbecken**: mindestens 15 × 8 Blöcke und 4 Blöcke hoch, 173 eigene Wasserblöcke
  ([Größenregel](../big_tanks.md)).
* Sie lebt in einer **Höhle**: bau ihr eine Felshöhle oder einen Überhang (Deko im Innenraum). Dort sucht sie sich einen
  geschützten Platz und liegt den größten Teil des Tages darin, der Körper wiegt sich langsam und das Maul öffnet und
  schließt sich - so atmet sie, das ist keine Drohung. Ohne Deko nimmt sie eine Ecke am Boden.
* Nachts kommt sie heraus und zieht durchs Becken; fütterst du von Hand, kommt sie zum Futter heraus.
* Sie verschlingt Fische bis 0,8 Blöcke, Bettas und Garnelen: halte sie nur mit großen Tieren. Sie vermehrt sich nicht im
  Becken.

## Bezug

* **[Großer Kescher](large_net.md)** in warmen Ozeanen (Korallenriffe): 1,1 % pro Schwung (etwa 1 von 88 Schwüngen), in eine leere Transportwanne (Config `features.bigAnimals`).
* **[Stahlvorfach](steel_leader.md)** (Angeln) in warmen Ozeanen (Korallenriffe): 1,4 % pro Fang (etwa 1 von 70 Fängen), in eine leere Transportwanne (Config `features.bigAnimals`).
* **Wild** in warmen Ozeanen (Korallenriffe), einzeln (Spawn-Gewicht 2) (Config `features.bigAnimals`).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
