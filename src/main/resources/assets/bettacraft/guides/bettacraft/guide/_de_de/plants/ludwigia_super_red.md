# Ludwigia „Super Red“

![Ludwigia „Super Red“](../images/sp_ludwigia_super_red.png)

*Ludwigia palustris* „Super Red“, eine auf Farbe gezüchtete Form: tief weinrote Blätter.

## Steckbrief

| | |
|---|---|
| Wuchsform | Stängelpflanze |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | viel |
| Volle Größe | nach etwa 3,5 Tagen |
| Breitet sich aus | Seitentriebe |
| Ableger pro Schnitt | 3 |
| Farbe | röter bei viel Licht |
| CO2 | nötig: ohne CO2 wächst sie mit 40 % Geschwindigkeit |

## Haltung

* Schnell; bei viel Licht am rötesten.
* Wächst nur mit [CO2](../equipment/co2.md) richtig.

## Bezug

* **Angeln** in Sümpfen: 0,13 % pro Fang (etwa 1 von 793 Fängen), statt des Fischs.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 3 Ableger pro Schnitt; sie breitet sich auch selbst aus (Seitentriebe).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
