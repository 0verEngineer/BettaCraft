# Bolivianischer Schmetterlingsbuntbarsch

![Bolivianischer Schmetterlingsbuntbarsch](../images/tm_bolivian_ram.png)

Größer, ruhiger und robuster als der Schmetterlingsbuntbarsch: beige mit gelbem Vorderkörper, einem schwarzen Fleck in der Mitte und roten Flossensäumen.

**Herkunft:** Río Mamoré und Río Guaporé in Bolivien und Brasilien.

## Steckbrief

| | |
|---|---|
| Gruppe | Buntbarsche |
| Wissenschaftlicher Name | *Mikrogeophagus altispinosus* |
| Größe im Spiel | etwa 7,5 cm (0,62 Blöcke) |
| Temperatur | 22–29 °C |
| Zuchttemperatur | 25–28 °C |
| Wasser | Süßwasser, normal |
| Wasserchemie | pH 6,0–8,0, TDS 0–450 ppm |

| Schwimmt | im unteren Wasser |

| Zucht | Offenbrüter: das Paar laicht auf Stein, Blatt oder Scheibe und bewacht die Brut, 20–60 Junge |
| Betta-Becken | mit Vorsicht (großes Becken) |
| Besonderheiten | bewacht seine Brut, revierbildend |

## Zucht

Bei 25–28 °C findet sich ein Paar: Das Männchen und das nächste freie Weibchen putzen einen **flachen Stein** (sonst eine Grube im Bodengrund) und laichen dort 20–60 Eier. Beide Eltern bleiben an der Brut, fächeln den Eiern Wasser zu und **vertreiben jeden anderen Fisch** (auch Bettas: der Eindringling flieht und wird gebissen, Config `tankmates.behaviour.broodDefence`). Bewachte Eier sind vor den anderen Fischen sicher; sind beide Eltern weg, stirbt die Brut.

## Haltung

* Verträgt kühleres und härteres Wasser als der Schmetterlingsbuntbarsch (22–29 °C).
* Männchen sind revierbildend: jedes braucht etwa 3 Wasserblöcke; in einem kleineren Becken werden die überzähligen Männchen gejagt und gebissen.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,51–0,61 % pro Schwung (etwa 1 von 165–195 Schwüngen).
* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,11–0,13 % pro Schwung (etwa 1 von 789–935 Schwüngen).
* **Wild** in Flüssen, in Gruppen von 1–1 (Spawn-Gewicht 2) (Config `features.cichlids`).
* **Wild** in Dschungelgewässern, in Gruppen von 1–1 (Spawn-Gewicht 1) (Config `features.cichlids`).
* **Fahrender Händler** (seltene Angebote): 2 für 7 Smaragde; eins von 11 in diesem Angebot.
* **[Zucht](breeding.md)**: Offenbrüter: das Paar laicht auf Stein, Blatt oder Scheibe und bewacht die Brut.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
