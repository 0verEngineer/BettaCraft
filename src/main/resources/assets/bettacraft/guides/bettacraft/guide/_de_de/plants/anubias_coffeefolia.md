# Anubias coffeefolia

![Anubias coffeefolia](../images/sp_anubias_coffeefolia.png)

*Anubias barteri* var. *coffeefolia* aus Westafrika: dunkelgrüne, gewellte Blätter wie beim Kaffeestrauch; die jungen Blätter entfalten sich rotbraun.

## Steckbrief

| | |
|---|---|
| Wuchsform | Aufsitzerpflanze (Rhizom) |
| Wächst auf | Stein und Holz (auch Deko) |
| Licht | wenig |
| Volle Größe | nach etwa 25 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* Auf Stein oder Holz; langsam und robust.
* Wenig Licht genügt.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,39–0,47 % pro Schwung (etwa 1 von 212–254 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Dschungelgewässern: 0,19 % pro Fang (etwa 1 von 540 Fängen), statt des Fischs.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt; ein abgebautes Rhizomstück teilt sie.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
