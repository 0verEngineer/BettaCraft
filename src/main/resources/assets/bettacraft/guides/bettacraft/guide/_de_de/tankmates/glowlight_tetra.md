# Glühlichtsalmler

![Glühlichtsalmler](../images/tm_glowlight_tetra.png)

Durchscheinend mit einer orangeroten Leuchtlinie von der Schnauze bis zum Schwanz.

**Herkunft:** den Essequibo in Guyana.

## Steckbrief

| | |
|---|---|
| Gruppe | Salmler |
| Wissenschaftlicher Name | *Hemigrammus erythrozonus* |
| Größe im Spiel | etwa 3,5 cm (0,29 Blöcke) |
| Temperatur | 23–28 °C |
| Zuchttemperatur | 25–28 °C |
| Wasser | Süßwasser, normal |
| Wasserchemie | pH 5,0–7,8, TDS 0–450 ppm |
| Schwarm | ab 6 Tieren |
| Schwimmt | in der Mitte |
| Besatz | zählt als 0,35 Fisch |
| Zucht | Freilaicher (feinblättrige Pflanzen, Laichmop), 20–50 Junge |
| Betta-Becken | ja |

## Zucht

Bei 25–28 °C streut ein Paar 20–50 Eier in feinblättrige Pflanzen, Javamoos oder einen **Laichmop**. Die Eltern und alle anderen Fische fressen erreichbare Eier; im Laichmop sind die meisten sicher. Lebendfutter (Mückenlarven) macht die Fische laichbereiter.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,67–0,79 % pro Schwung (etwa 1 von 126–150 Schwüngen), 1–4 auf einmal.
* **Wild** in Dschungelgewässern, in Gruppen von 3–6 (Spawn-Gewicht 8) (Config `features.wildFish`).
* **Fahrender Händler** (seltene Angebote): 6 für 7 Smaragde; eins von 12 in diesem Angebot.
* **[Zucht](breeding.md)**: Freilaicher (feinblättrige Pflanzen, Laichmop).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
