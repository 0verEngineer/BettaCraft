# Bacopa caroliniana

![Bacopa caroliniana](../images/sp_bacopa_caroliniana.png)

*Bacopa caroliniana* aus den Sümpfen Nordamerikas: dicke, runde Blätter an kräftigen Stängeln.

## Steckbrief

| | |
|---|---|
| Wuchsform | Stängelpflanze |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | mittel |
| Volle Größe | nach etwa 4 Tagen |
| Breitet sich aus | Seitentriebe |
| Ableger pro Schnitt | 3 |
| Farbe | rote Spitzen bei viel Licht |

## Haltung

* Robust; mittleres Licht.
* Die Spitzen werden bei viel Licht kupferfarben.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 0,38–0,46 % pro Schwung (etwa 1 von 217–260 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Sümpfen: 0,19 % pro Fang (etwa 1 von 528 Fängen), statt des Fischs.
* **Schere** an einem wilden Pflanzenbestand in Sümpfen: 100 % pro Schnitt (Config `features.wildPlants`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 3 Ableger pro Schnitt; sie breitet sich auch selbst aus (Seitentriebe).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
