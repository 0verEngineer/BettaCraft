# Amazonas-Froschbiss

![Amazonas-Froschbiss](../images/sp_amazon_frogbit.png)

Amazonas-Froschbiss (*Limnobium laevigatum*) aus Mittel- und Südamerika: runde Blätter mit langen Wurzeln, die ins Wasser hängen.

## Steckbrief

| | |
|---|---|
| Wuchsform | Schwimmpflanze |
| Blattgröße | bis 6,2 cm |
| Wachstum | mittel |
| Nimmt Abfall auf | ×1,3 |
| Nestplatz | der liebste |
| Wurzeln | lang |

## Haltung

* Der **liebste Nestplatz** des Betta-Männchens.
* Seine Wurzeln sind ein Versteck für Jungfische.

## Bezug

* **Angeln** in Sümpfen: 1,2 % pro Fang (etwa 1 von 84 Fängen), statt des Fischs.
* **Angeln** in Mangrovensümpfen: 1,3 % pro Fang (etwa 1 von 80 Fängen), statt des Fischs.
* **Fahrender Händler** (übliche Angebote): 2 für 1 Smaragd.
* **Ableger**: wächst auf einer beleuchteten Wasseroberfläche und bildet Ableger; mit dem Kescher herausnehmen.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
