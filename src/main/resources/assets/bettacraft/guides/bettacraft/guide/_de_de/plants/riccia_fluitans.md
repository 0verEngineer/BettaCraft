# Teichlebermoos (Riccia)

![Teichlebermoos (Riccia)](../images/sp_riccia_fluitans.png)

Teichlebermoos (*Riccia fluitans*): ein Lebermoos aus kleinen, gegabelten Thalli; auf Stein oder Holz gebunden wird es zu einem leuchtenden Polster, an der Oberfläche schwimmt es.

## Steckbrief

| | |
|---|---|
| Wuchsform | Moos |
| Wächst auf | Stein und Holz (auch Deko); oder schwimmend an der Oberfläche |
| Licht | viel |
| Volle Größe | nach etwa 4 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 2 |
| Schwimmend | ja: von außen auf ein Aquarium anwenden |

## Haltung

* Im Innenraum auf Stein oder Holz **gebunden** (nicht auf den Boden) braucht es **viel Licht**.
* **Schwimmend**: dasselbe Item von außen auf ein Aquarium anwenden, es schwimmt wie eine [Schwimmpflanze](floating_plants.md) und Männchen bauen ihr Schaumnest gern darin.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 0,23–0,28 % pro Schwung (etwa 1 von 361–433 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Sümpfen: 0,13 % pro Fang (etwa 1 von 793 Fängen), statt des Fischs.
* **Wilde Schwimmpflanzen abbauen** in Sümpfen: 100 % pro Block (Config `features.wildPlants`).
* **Schere** an einem wilden Pflanzenbestand in Flüssen: 100 % pro Schnitt (Config `features.wildPlants`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 2 Ableger pro Schnitt.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
