# Süßwasserstechrochen

![Süßwasserstechrochen von oben](../images/tm_motoro_stingray.png)

Ein Stechrochen des Süßwassers: eine runde, flache Scheibe, warmbraun mit orangefarbenen, schwarz umrandeten
Augenflecken, kleinen Augen oben und einem dicken Schwanz mit giftigem Stachel. Die Scheibe wird etwa 45 cm groß, mit
Schwanz 0,6 m.

**Herkunft:** der Amazonas und die Flüsse des Paraná-Beckens.

## Steckbrief

| | |
|---|---|
| Gruppe | Rochen |
| Wissenschaftlicher Name | *Potamotrygon motoro* |
| Größe | etwa 0,6 m (1,2 Blöcke im Spiel) |
| Becken | mindestens 8 × 4 Blöcke, 2 hoch, je 22 Wasserblöcke |
| Temperatur | 24–30 °C |
| Zuchttemperatur | 26–29 °C |
| Wasser | Süßwasser, empfindlich |
| Wasserchemie | pH 5,5–7,5, TDS 0–300 ppm |
| Schwarm | einzeln oder als Paar |
| Schwimmt | am Boden |
| Besatz | zählt als 5,4 Fisch |
| Zucht | lebendgebärend, 2–5 Junge |
| Betta-Becken | nein (zu groß) |
| Besonderheiten | frisst kleine Fische und Garnelen, gleitet über den Boden und liegt auf dem Bodengrund |

## Haltung

* Ein großes Tier: es braucht ein Becken von mindestens 8 × 4 Blöcken und 2 Blöcken Höhe und 22 eigene Wasserblöcke
  ([Größenregel](../big_tanks.md)). Er braucht **Bodenfläche** mehr als Höhe.
* Er gleitet dicht über den Boden, eine Welle läuft am Rand seiner Scheibe nach hinten, und liegt lange still auf dem
  Bodengrund; gib ihm feinen Sand und halte die Mitte des Bodens frei von Deko.
* Weiches, warmes und sehr sauberes Wasser (24–30 °C): er ist empfindlich gegen Schmutz.
* Er frisst Würmer, Garnelen und kleine Bodenfische.

## Zucht

Der Stechrochen ist **lebendgebärend**: ein Weibchen trägt seine Jungen etwa viermal so lange wie die kleinen
Lebendgebärenden und bringt dann **2–5 Junge** zur Welt. Die Jungen kommen fertig entwickelt und groß zur Welt und brauchen
deshalb Platz: ein Weibchen wird nur trächtig, solange das Becken nach der [Größenregel](../big_tanks.md) Platz für ein
weiteres erwachsenes Tier hat, und es werden nur so viele Junge geboren, wie Platz ist. Sie kommen nicht in einen
Ablaichkasten, und die anderen Fische fressen sie nicht.

## Bezug

* **[Großer Kescher](large_net.md)** in Dschungelgewässern: 1,1 % pro Schwung (etwa 1 von 88 Schwüngen), in eine leere Transportwanne (Config `features.bigTanks.bigAnimals`).
* **[Stahlvorfach](steel_leader.md)** (Angeln) in Dschungelgewässern: 1,4 % pro Fang (etwa 1 von 70 Fängen), in eine leere Transportwanne (Config `features.bigTanks.bigAnimals`).
* **Wild** in Dschungelgewässern, einzeln (Spawn-Gewicht 2) (Config `features.bigTanks.bigAnimals`).
* **[Zucht](../tankmates/breeding.md)**: lebendgebärend.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
