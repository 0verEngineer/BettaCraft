# Kardinalgarnele (Sulawesi)

![Kardinalgarnelen und Tylomelania-Schnecken auf Kalkstein](../images/critters_sulawesi.png)

Die Kardinalgarnele (*Caridina dennerli*) lebt nur in den alten Seen von **Sulawesi**: tiefrot mit weißen Punkten,
klein und scheu. Sie ist das Gegenstück zur [Bienengarnele](caridina.md): Sie braucht **hartes, warmes, basisches
Wasser**. Am besten teilt sie ihr Becken mit den [Tylomelania-Schnecken](tylomelania.md) derselben Seen.

## Steckbrief

| | |
|---|---|
| Gruppe | Garnelen |
| Größe im Spiel | etwa 2 cm (0,17 Blöcke) |
| Temperatur | 25–31 °C |
| Wasser | Süßwasser, empfindlich |
| Wasserchemie | pH 7,5–8,6, TDS 150–350 ppm |
| Vermehrung | Männchen und Weibchen; das Weibchen trägt die Eier, die Jungen schlüpfen fertig entwickelt, 1–4 Junge |
| Heranwachsen | etwa 5 Tage |
| Algen | weidet 0,1 Scheiben am Tag ab |
| Klettert an der Scheibe | ja |
| Besatz | 25 zählen als ein Fisch |

## Das richtige Wasser

* **pH 7,5 bis 8,6 und TDS 150 bis 350 ppm**, 25 bis 31 °C. Normales Wasser passt gerade (pH 7,5 ist die untere
  Grenze): **Kalkstein** am Boden oder als Steine (Kalzit, Tropfstein, tote Korallen …) hebt den pH und hält ihn dort.
* Kein Soil, Torf, keine Wurzeln oder Seemandelbaumblätter: Sie machen das Wasser zu sauer. Das
  [CO2](../equipment/co2.md) niedrig halten.
* Empfindlich gegen schlechtes Wasser: oft wechseln.

## Zucht

* Ein Weibchen trägt seine wenigen Eier 3 Tage, dann schlüpfen 1 bis 4 Junge; sie brauchen 5 Tage, um heranzuwachsen.
  Eine Kolonie wächst langsam.
* Sie weiden Glas und Steine etwas mehr ab als die Bienengarnelen.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 1–2,2 % pro Schwung (etwa 1 von 45–96 Schwüngen), 1–3 auf einmal (Config `features.sulawesi`).
* **Wild** in Dschungelgewässern, in Gruppen von 2–5 (Spawn-Gewicht 1) (Config `features.sulawesi`).
* **Fahrender Händler** (seltene Angebote): 2 für 7 Smaragde; eins von 2 in diesem Angebot (Config `features.sulawesi`).
* **Vermehrung** im Aquarium (Männchen und Weibchen).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
