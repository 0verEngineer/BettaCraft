# Cryptocoryne parva

![Cryptocoryne parva](../images/sp_cryptocoryne_parva.png)

*Cryptocoryne parva* aus Sri Lanka: die kleinste Cryptocoryne, schmale Blättchen.

## Steckbrief

| | |
|---|---|
| Wuchsform | Rosettenpflanze |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | wenig |
| Volle Größe | nach etwa 16 Tagen |
| Breitet sich aus | Ausläufer |
| Ableger pro Schnitt | 1 |

## Haltung

* Sehr langsam, wenig Licht.
* Wird mit der Zeit über Ausläufer zu einem Rasen.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,16–0,19 % pro Schwung (etwa 1 von 521–625 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Flüssen: 0,1 % pro Fang (etwa 1 von 1033 Fängen), statt des Fischs.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt; sie breitet sich auch selbst aus (Ausläufer).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
