# Myriophyllum „Red“

![Myriophyllum „Red“](../images/sp_myriophyllum_red.png)

*Myriophyllum tuberculatum* „Red“: fedrige Quirle in tiefem Rot.

## Steckbrief

| | |
|---|---|
| Wuchsform | Stängelpflanze |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | viel |
| Volle Größe | nach etwa 3 Tagen |
| Breitet sich aus | Seitentriebe |
| Ableger pro Schnitt | 3 |
| Farbe | röter bei viel Licht |
| CO2 | nötig: ohne CO2 wächst sie mit 40 % Geschwindigkeit |
| Wasserchemie | weiches Wasser: am besten bis pH 7 und 300 TDS, langsamer in hartem Wasser |

## Haltung

* Anspruchsvoll: viel Licht, [CO2](../equipment/co2.md) und weiches Wasser ([Wasserchemie](../aquarium/water_chemistry.md)).
* Bei viel Licht röter.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 0,19–0,23 % pro Schwung (etwa 1 von 433–520 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Sümpfen: 0,09 % pro Fang (etwa 1 von 1057 Fängen), statt des Fischs.
* **Schere** an einem wilden Pflanzenbestand in Sümpfen: 100 % pro Schnitt (Config `features.wildPlants`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 3 Ableger pro Schnitt; sie breitet sich auch selbst aus (Seitentriebe).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
