# Gelbe Rennschnecke

![Gelbe Rennschnecke](../images/sp_yellow_nerite.png)

Die Gelbe Rennschnecke, die gelbe Form von *Vittina waigiensis*: gelb oder goldgelb, manche mit dunklen Linien.

## Steckbrief

| | |
|---|---|
| Gruppe | Schnecken |
| Größe im Spiel | etwa 2 cm (0,16 Blöcke) |
| Temperatur | 20–28 °C |
| Wasser | Süß-, Brack- oder Meerwasser, normal |
| Wasserchemie | pH 6,8–8,6, TDS 100–700 ppm |
| Vermehrung | keine Jungen im Süßwasser |
| Algen | weidet 2 Scheiben am Tag ab |
| Klettert an der Scheibe | ja |
| Besatz | 50 zählen als ein Fisch |

## Haltung

* Jede hat ihren eigenen Farbton; er lässt sich nicht züchten.
* Nur mit `features.snailColors`; vermehrt sich im Süßwasser nie.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Mangrovensümpfen: 1,3–1,5 % pro Schwung (etwa 1 von 67–79 Schwüngen) (Config `features.snailColors`).
* **Wild** in Mangrovensümpfen, in Gruppen von 2–5 (Spawn-Gewicht 1) (Config `features.snailColors`).
* **Fahrender Händler** (seltene Angebote): 2 für 4 Smaragde; eins von 2 in diesem Angebot (Config `features.snailColors`).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
