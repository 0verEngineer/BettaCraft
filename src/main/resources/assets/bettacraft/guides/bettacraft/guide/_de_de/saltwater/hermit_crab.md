# Blaubein-Einsiedlerkrebs

![Blaubein-Einsiedlerkrebs](../images/sp_hermit_crab.png)

Der Blaubein-Einsiedlerkrebs (*Clibanarius tricolor*) aus der Karibik: ein kleiner Krebs mit blauen Beinen in einem geliehenen Schneckenhaus, Teil der Putzkolonne eines Riffbeckens.

## Steckbrief

| | |
|---|---|
| Gruppe | Einsiedlerkrebse |
| Größe im Spiel | etwa 2,5 cm (0,2 Blöcke) |
| Temperatur | 22–28 °C |
| Wasser | Meerwasser, auch starkes Brackwasser, normal |
| Vermehrung | vermehrt sich nicht im Aquarium |
| Algen | weidet 0,8 Scheiben am Tag ab |
| Klettert an der Scheibe | ja |
| Besatz | 50 zählen als ein Fisch |

## Haltung

* Weidet Algen und frisst Futterreste.
* Robust: auch in starkem Brackwasser ab 20 ‰; auch an Stränden zu fangen.
* Er vermehrt sich nicht im Aquarium.

## Bezug

* **[Kescher](../equipment/tank_net.md)** an Stränden: 4,5–5,4 % pro Schwung, 1–2 auf einmal.
* **[Kescher](../equipment/tank_net.md)** in warmen Ozeanen (Korallenriffe): 9,6–12 % pro Schwung, 1–2 auf einmal.
* **[Kescher](../equipment/tank_net.md)** in lauwarmen Ozeanen: 13–16 % pro Schwung, 1–2 auf einmal.
* **Fahrender Händler** (seltene Angebote): 3 für 5 Smaragde; eins von 2 in diesem Angebot.
