# Perlhuhnbärbling

![Perlhuhnbärbling](../images/tm_celestial_pearl_danio.png)

Ein winziges Juwel: blaugrau mit goldenen Perlpunkten; das Männchen hat einen orangen Bauch und rotorange Flossen mit schwarzen Binden.

**Herkunft:** kleine, verkrautete Teiche im Hochland Myanmars.

## Steckbrief

| | |
|---|---|
| Gruppe | Bärblinge |
| Wissenschaftlicher Name | *Celestichthys margaritatus* |
| Größe im Spiel | etwa 2 cm (0,17 Blöcke) |
| Temperatur | 20–26 °C |
| Zuchttemperatur | 22–25 °C |
| Wasser | Süßwasser, empfindlich |
| Wasserchemie | pH 5,0–7,8, TDS 0–450 ppm |
| Schwarm | ab 6 Tieren |
| Schwimmt | im unteren Wasser |
| Besatz | zählt als 0,15 Fisch |
| Zucht | Freilaicher (feinblättrige Pflanzen, Laichmop), 10–30 Junge |
| Betta-Becken | zu kühl |

## Zucht

Bei 22–25 °C streut ein Paar 10–30 Eier in feinfiedrige Pflanzen, Javamoos oder einen **Laichmopp**. Die Eltern und alle anderen Fische fressen die Eier, die sie erreichen; im Laichmopp sind die meisten sicher. Lebendfutter bringt sie schneller in Laichstimmung.

## Haltung

* Scheu: bleibt unten zwischen dichten Pflanzen; weiches Wasser, 20–26 °C.
* Klein genug fürs Nano-Becken und ruhig genug fürs Betta-Becken (am oberen Ende seiner Temperatur).

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 0,8–0,95 % pro Schwung (etwa 1 von 106–125 Schwüngen), 1–4 auf einmal.
* **Wild** in Sümpfen, in Gruppen von 3–6 (Spawn-Gewicht 4) (Config `features.tankmates.communityFish`).
* **Fahrender Händler** (übliche Angebote): 6 für 3 Smaragde; eins von 36 in diesem Angebot.
* **[Zucht](breeding.md)**: Freilaicher (feinblättrige Pflanzen, Laichmop).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
