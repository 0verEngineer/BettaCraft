# Zwergseepferdchen

![Zwergseepferdchen](../images/sp_dwarf_seahorse.png)

Das Zwergseepferdchen (*Hippocampus zosterae*) aus den Seegraswiesen Floridas, der Bahamas und des Golfs von Mexiko: eines der kleinsten Seepferdchen, nur 2–3 cm groß.

## Steckbrief

| | |
|---|---|
| Gruppe | Seepferdchen |
| Wissenschaftlicher Name | *Hippocampus zosterae* |
| Größe im Spiel | etwa 2,5 cm (0,22 Blöcke) |
| Temperatur | 21–28 °C |
| Zuchttemperatur | 24–27 °C |
| Wasser | Meerwasser, auch starkes Brackwasser, empfindlich |
| Wasserchemie | pH 7,8–8,6 |
| Schwarm | einzeln oder als Paar |
| Schwimmt | im unteren Wasser |
| Besatz | zählt als 0,3 Fisch |
| Zucht | Bruttasche: das Männchen trägt die Eier, 3–10 Junge |

## Haltung

* Passt in kleine Becken (zählt als 0,3).
* Wie das Gestreifte Seepferdchen: Haltepunkte, wenig Strömung, zweimal am Tag Lebendfutter.
* Vermehrt sich bei 24–27 °C; die Jungen fressen vom ersten Tag an Artemia-Nauplien.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in warmen Ozeanen (Korallenriffe): 0,83–0,99 % pro Schwung (etwa 1 von 101–120 Schwüngen) (Config `features.saltwater.seahorses`).
* **Wild** in warmen Ozeanen (Korallenriffe), einzeln (Spawn-Gewicht 2) (Config `features.saltwater.seahorses`).
* **Fahrender Händler** (seltene Angebote): 2 für 5 Smaragde; eins von 3 in diesem Angebot (Config `features.saltwater.seahorses`).
* **[Zucht](seahorses.md)**: Bruttasche: das Männchen trägt die Eier.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
