# Neon-Zwergregenbogenfisch

![Neon-Zwergregenbogenfisch](../images/tm_neon_dwarf_rainbow.png)

Ein hochrückiger Regenbogenfisch mit zwei Rückenflossen und leuchtend neonblauen Schuppen; das Männchen hat rote Flossen, das Weibchen gelbliche.

**Herkunft:** die Flüsse des Mamberamo-Beckens im Westen Neuguineas.

## Steckbrief

| | |
|---|---|
| Gruppe | Regenbogenfische |
| Wissenschaftlicher Name | *Melanotaenia praecox* |
| Größe im Spiel | etwa 6 cm (0,5 Blöcke) |
| Temperatur | 23–28 °C |
| Zuchttemperatur | 25–27 °C |
| Wasser | Süßwasser, normal |
| Wasserchemie | pH 6,5–8,5, TDS 50–700 ppm |
| Schwarm | ab 6 Tieren |
| Schwimmt | in der Mitte |
| Besatz | zählt als 0,6 Fisch |
| Zucht | Freilaicher (feinblättrige Pflanzen, Laichmop), 15–40 Junge |
| Betta-Becken | ja |

## Zucht

Bei 25–27 °C streut ein Paar 15–40 Eier in feinfiedrige Pflanzen, Javamoos oder einen **Laichmopp**. Die Eltern und alle anderen Fische fressen die Eier, die sie erreichen; im Laichmopp sind die meisten sicher. Lebendfutter bringt sie schneller in Laichstimmung.

## Haltung

* Aktive Schwimmer: Platz und einen Schwarm ab 6 geben.
* Friedlich; die Männchen imponieren einander im Morgenlicht.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,36–0,42 % pro Schwung (etwa 1 von 238–281 Schwüngen), 1–4 auf einmal.
* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,27–0,32 % pro Schwung (etwa 1 von 316–374 Schwüngen), 1–4 auf einmal.
* **Wild** in Flüssen, in Gruppen von 3–6 (Spawn-Gewicht 2) (Config `features.tankmates.communityFish`).
* **Wild** in Dschungelgewässern, in Gruppen von 3–6 (Spawn-Gewicht 3) (Config `features.tankmates.communityFish`).
* **Fahrender Händler** (übliche Angebote): 6 für 5 Smaragde; eins von 36 in diesem Angebot.
* **[Zucht](breeding.md)**: Freilaicher (feinblättrige Pflanzen, Laichmop).
