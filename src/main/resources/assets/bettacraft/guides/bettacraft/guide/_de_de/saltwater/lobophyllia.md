# Lobophyllia

![Lobophyllia](../images/sp_lobophyllia.png)

*Lobophyllia* (Gelappte Hirnkoralle) aus dem Indopazifik: eine Steinkoralle (LPS), die zu einer fleischigen Kuppel aus roten und grünen Lappen wächst.

## Steckbrief

| | |
|---|---|
| Wuchsform | Kuppel (Steinkoralle) |
| Wächst auf | Riffgestein, lebendem Gestein |
| Licht | mittel |
| Strömung | sanft |
| Kalzium | baut ein Skelett, verbraucht Kalzium |
| Wasser | Meerwasser |
| Volle Größe | nach etwa 15 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* Baut ein Skelett: braucht **Kalzium**.
* Mittleres Licht, sanfte Strömung.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in warmen Ozeanen (Korallenriffe): 0,12–0,14 % pro Schwung (etwa 1 von 694–833 Schwüngen).
* **Schere** an einem wilden Korallenstock in warmen Ozeanen (Korallenriffe): 100 % pro Schnitt (Config `features.corals.wildCorals`).
* **Ableger**: eine Schere an einer gewachsenen Koralle gibt 1 Ableger pro Schnitt.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
