# Bucephalandra „Godzilla“

![Bucephalandra „Godzilla“](../images/sp_bucephalandra_godzilla.png)

*Bucephalandra* „Godzilla“ aus Borneo: eine der großen, breite, gewellte Blätter in Olivbraun.

## Steckbrief

| | |
|---|---|
| Wuchsform | Aufsitzerpflanze (Rhizom) |
| Wächst auf | Stein und Holz (auch Deko) |
| Licht | wenig |
| Volle Größe | nach etwa 24 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |
| Farbe | röter bei viel Licht |

## Haltung

* Auf Stein oder Holz; langsam.
* Bei viel Licht röter.

## Bezug

* **Angeln** in Flüssen: 0,11 % pro Fang (etwa 1 von 913 Fängen), statt des Fischs.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt; ein abgebautes Rhizomstück teilt sie.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
