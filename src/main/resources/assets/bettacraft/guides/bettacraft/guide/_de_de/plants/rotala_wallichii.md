# Rotala wallichii

![Rotala wallichii](../images/sp_rotala_wallichii.png)

*Rotala wallichii* aus Süd- und Südostasien: feine Nadelblätter in dichten Quirlen mit rosa Spitzen.

## Steckbrief

| | |
|---|---|
| Wuchsform | Stängelpflanze |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | sehr viel (LED-Panel oder Hochleistungs-LED) |
| Volle Größe | nach etwa 3,5 Tagen |
| Breitet sich aus | Seitentriebe |
| Ableger pro Schnitt | 3 |
| Farbe | rote Spitzen bei viel Licht |
| CO2 | nötig: ohne CO2 wächst sie mit 40 % Geschwindigkeit |
| Wasserchemie | weiches Wasser: am besten bis pH 7 und 300 TDS, langsamer in hartem Wasser |

## Haltung

* Anspruchsvoll: sehr viel Licht ([LED-Panel oder Hochleistungs-LED](../equipment/light.md)), [CO2](../equipment/co2.md) und weiches Wasser ([Wasserchemie](../aquarium/water_chemistry.md)).
* Die Spitzen werden bei viel Licht rosa.

## Bezug

* **Angeln** in Sümpfen: 0,1 % pro Fang (etwa 1 von 979 Fängen), statt des Fischs.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 3 Ableger pro Schnitt; sie breitet sich auch selbst aus (Seitentriebe).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
