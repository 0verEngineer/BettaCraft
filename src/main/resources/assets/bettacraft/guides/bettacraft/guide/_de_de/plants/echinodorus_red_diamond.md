# Echinodorus „Red Diamond“

![Echinodorus „Red Diamond“](../images/sp_echinodorus_red_diamond.png)

*Echinodorus* „Red Diamond“: eine kompakte Schwertpflanze mit weinroten Blättern.

## Steckbrief

| | |
|---|---|
| Wuchsform | Rosettenpflanze |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | mittel |
| Volle Größe | nach etwa 8 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |
| Farbe | röter bei viel Licht |

## Haltung

* Mittleres Licht; je stärker das Licht, desto röter die Blätter.
* Kleiner als die Amazonas-Schwertpflanze: passt auch in kleinere Becken.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,23–0,27 % pro Schwung (etwa 1 von 369–443 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Dschungelgewässern: 0,14 % pro Fang (etwa 1 von 730 Fängen), statt des Fischs.
* **Schere** an einem wilden Pflanzenbestand in Dschungelgewässern: 100 % pro Schnitt (Config `features.wildPlants`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
