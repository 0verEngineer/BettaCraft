# Bucephalandra „Theia“

![Bucephalandra „Theia“](../images/sp_bucephalandra_theia.png)

*Bucephalandra* „Theia“ aus Borneo: hellgrüne, leicht gewellte Blätter an einem kompakten Rhizom.

## Steckbrief

| | |
|---|---|
| Wuchsform | Aufsitzerpflanze (Rhizom) |
| Wächst auf | Stein und Holz (auch Deko) |
| Licht | wenig |
| Volle Größe | nach etwa 20 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* Auf Stein oder Holz; langsam.
* Wenig Licht genügt.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,29–0,35 % pro Schwung (etwa 1 von 289–347 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Flüssen: 0,15 % pro Fang (etwa 1 von 685 Fängen), statt des Fischs.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt; ein abgebautes Rhizomstück teilt sie.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
