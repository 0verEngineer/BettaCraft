# Zwergfadenfisch

Blau-rot gestreifte Männchen mit langen Fühlern; ein Labyrinthfisch wie der Betta - Fadenfisch- und Betta-Männchen kämpfen.

| | |
|---|---|
| Familie | Fadenfische |
| Wissenschaftlich | *Trichogaster lalius* |
| Größe im Spiel | etwa 7 cm (0,55 Blöcke) |
| Herkunft | pflanzenreiche Gewässer Indiens und Bangladeschs |
| Temperatur | 24–29 °C |
| Schwarm | einzeln oder paarweise |
| Wasser | normal |
| Besatz | 1 Fisch |
| Zucht | baut ein Schaumnest, 26–29 °C |

## Farbformen

Farbformen: Wildform (blau-rot), Neonblau (Powder Blue), Feuer (Flame). Die Wildform ist dominant, Zuchtformen sind rezessiv: Erst zwei gleiche Allele zeigen die Farbe (Träger sehen wild aus). Von zwei verschiedenen Zuchtformen zeigt sich die zuerst genannte. Wildfänge tragen manchmal eine Zuchtform verdeckt; das Menü zeigt die Gene im Tooltip.

## Zucht

Wie ein Betta: Bei 26–29 °C baut das Männchen ein Schaumnest an der Oberfläche (Schwimmpflanzen helfen), das Weibchen laicht 20–50 Eier hinein, danach jagt das Männchen sie weg und bewacht das Nest.

## Haltung

* Betta-Männchen jagen die Männchen dieser Art (Config `tankmates.behaviour.bettaAggression`).

## Beschaffung

Mit dem [Kescher](../invertebrates/catching.md) in Sümpfen und beim fahrenden Händler; danach durch Zucht.
