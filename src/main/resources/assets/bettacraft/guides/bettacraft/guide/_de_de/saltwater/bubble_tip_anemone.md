# Blasenanemone

![Blasenanemone](../images/sp_bubble_tip_anemone.png)

Die Blasenanemone (*Entacmaea quadricolor*) aus dem Indopazifik: eine Seeanemone mit blasigen Tentakelspitzen auf einem haftenden Fuß, das Zuhause der Clownfische.

## Steckbrief

| | |
|---|---|
| Wuchsform | Anemone |
| Wächst auf | Riffgestein, lebendem Gestein |
| Licht | mittel |
| Strömung | mittel |
| Kalzium | nicht nötig (Weichkoralle) |
| Wasser | Meerwasser |
| Volle Größe | nach etwa 6 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* In jede Anemone zieht ein Paar [Clownfische](ocellaris_clownfish.md) ein und laicht an ihrem Fuß.
* Mittleres Licht und mittlere Strömung, kein Kalzium.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in warmen Ozeanen (Korallenriffe): 0,6–0,72 % pro Schwung (etwa 1 von 139–167 Schwüngen).
* **Schere** an einem wilden Korallenstock in warmen Ozeanen (Korallenriffe): 100 % pro Schnitt (Config `features.corals.wildCorals`).
* **Fahrender Händler** (übliche Angebote): 2 für 4 Smaragde; eins von 4 in diesem Angebot.
* **Ableger**: eine Schere an einer gewachsenen Koralle gibt 1 Ableger pro Schnitt.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
