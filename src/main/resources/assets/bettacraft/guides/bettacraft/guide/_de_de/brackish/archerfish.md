# Schützenfisch

![Ein Schützenfisch schießt einen Wasserstrahl auf die Blätter einer Mangrove](../images/archer_shot.png)

Der Gebänderte Schützenfisch (*Toxotes jaculatrix*) der Mangroven von Indien bis Nordaustralien: silberweiß mit vier oder
fünf schwarzen Keilbinden, großen Augen und spitzem Kopf. Er schwimmt dicht unter der Oberfläche und **schießt Insekten mit
einem Wasserstrahl** aus dem Maul **von den Blättern über dem Wasser**.

![Schützenfisch](../images/sp_archerfish.png)

## Steckbrief

| | |
|---|---|
| Gruppe | Schützenfische |
| Wissenschaftlicher Name | *Toxotes jaculatrix* |
| Größe im Spiel | etwa 12 cm (1 Blöcke) |
| Temperatur | 24–30 °C |
| Wasser | Süß- oder Brackwasser, normal |
| Wasserchemie | pH 7,2–8,6 |
| Schwarm | ab 3 Tieren |
| Schwimmt | nahe der Oberfläche |
| Besatz | zählt als 2 Fisch |
| Zucht | vermehrt sich nicht im Aquarium |
| Betta-Becken | nein (groß, zupft Flossen) |
| Besonderheiten | frisst kleine Fische und Garnelen |

## Schießen

* Er braucht eine **offene Oberseite**: kein Deckel, Licht, Futterautomat oder voller Block über dem Wasser, wo er schießt
  (ein Licht über dem hinteren Teil des Beckens lässt vorne frei).
* **Fruchtfliegen:** Mit [Fruchtfliegen](../terrarium/feeder_insects.md) auf das Becken klicken: Sie werden über dem Wasser
  freigelassen (6 je Item, höchstens 24), und der Schützenfisch schießt sie eine nach der anderen ab, jede eine Mahlzeit.
* **Insekten an den Pflanzen:** Tagsüber kommen Insekten zu Pflanzen über einem offenen Becken: Blätter, Blumen oder
  Setzlinge oben auf dem Becken, die Krone einer [Mangrove](mangroves.md) über dem Wasser, das Land eines Paludariums
  (`brackish.archerfishInsectsPerDay`).
* Ab und zu **spritzt er einen Spieler an**, dessen Kopf über seinem offenen Becken ist: harmlos, es löscht nur ein Feuer
  (`brackish.archerfishSplashChance`).
* Er nimmt auch Pellets und Lebendfutter wie die anderen Fische.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Mangrovensümpfen: 3,8–4,5 % pro Schwung (etwa 1 von 22–27 Schwüngen), 1–4 auf einmal.
* **Wild** in Mangrovensümpfen, in Gruppen von 3–3 (Spawn-Gewicht 3) (Config `features.brackish.archerfish`).
* **Fahrender Händler** (seltene Angebote): 6 für 15 Smaragde; eins von 14 in diesem Angebot.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
