# Zebra-Rennschnecke

![Zebra-Rennschnecke](../images/sp_zebra_nerite.png)

Die Zebra-Rennschnecke (*Neritina natalensis*) aus den Mangroven und Flussmündungen Ostafrikas: ein rundes, gelbes Gehäuse mit schwarzen Zebrastreifen.

## Steckbrief

| | |
|---|---|
| Gruppe | Schnecken |
| Größe im Spiel | etwa 2 cm (0,17 Blöcke) |
| Temperatur | 20–28 °C |
| Wasser | Süß-, Brack- oder Meerwasser, normal |
| Vermehrung | keine Jungen im Süßwasser |
| Algen | weidet 2 Scheiben am Tag ab |
| Klettert an der Scheibe | ja |
| Besatz | 50 zählen als ein Fisch |

## Haltung

* Eine der **besten Algenfresserinnen**.
* Legt im Süßwasser keine Eier: sie vermehrt sich nie.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Mangrovensümpfen: 9–11 % pro Schwung, 1–2 auf einmal.
* **[Kescher](../equipment/tank_net.md)** an Stränden: 9–11 % pro Schwung, 1–2 auf einmal.
* **Wild** in Mangrovensümpfen, in Gruppen von 2–5 (Spawn-Gewicht 2) (Config `features.wildCritters`).
* **Wild** an Stränden, in Gruppen von 2–5 (Spawn-Gewicht 2) (Config `features.wildCritters`).
