# Anubias nana „Petite“

![Anubias nana „Petite“](../images/sp_anubias_nana_petite.png)

*Anubias barteri* var. *nana* „Petite“ (auch „Bonsai“), eine Zwergform aus den Gärtnereien: die kleinste Anubias, winzige dunkelgrüne Blätter dicht am Rhizom.

## Steckbrief

| | |
|---|---|
| Wuchsform | Aufsitzerpflanze (Rhizom) |
| Wächst auf | Stein und Holz (auch Deko) |
| Licht | wenig |
| Volle Größe | nach etwa 30 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* Auf Stein oder Holz; äußerst langsam, gut für den Vordergrund und Nano-Becken.
* Wenig Licht genügt.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,27–0,32 % pro Schwung (etwa 1 von 308–369 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Dschungelgewässern: 0,21 % pro Fang (etwa 1 von 487 Fängen), statt des Fischs.
* **Schere** an einem wilden Pflanzenbestand in Dschungelgewässern: 100 % pro Schnitt (Config `features.wildPlants`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt; ein abgebautes Rhizomstück teilt sie.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
