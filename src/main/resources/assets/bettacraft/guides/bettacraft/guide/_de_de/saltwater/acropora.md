# Acropora

![Acropora](../images/sp_acropora.png)

*Acropora*, die Geweih- und Tischkorallen, die die Riffe des Indopazifiks bauen: eine Steinkoralle (SPS) aus feinen Ästen, blau bis violett.

## Steckbrief

| | |
|---|---|
| Wuchsform | Äste (Steinkoralle) |
| Wächst auf | Riffgestein, lebendem Gestein |
| Licht | viel |
| Strömung | stark |
| Kalzium | baut ein Skelett, verbraucht Kalzium |
| Wasser | Meerwasser |
| Volle Größe | nach etwa 14 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* Die anspruchsvollste Koralle: **viel Licht, starke Strömung, Kalzium und sehr sauberes Wasser**.
* Bei schlechten Bedingungen wird sie als erste blass oder bleicht aus.

## Bezug

* **Ableger**: eine Schere an einer gewachsenen Koralle gibt 1 Ableger pro Schnitt.
