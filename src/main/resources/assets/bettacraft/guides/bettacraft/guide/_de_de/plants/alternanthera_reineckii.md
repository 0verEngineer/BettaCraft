# Alternanthera reineckii

![Alternanthera reineckii](../images/sp_alternanthera_reineckii.png)

*Alternanthera reineckii* aus Südamerika: eine Stängelpflanze mit tiefroten Blättern.

## Steckbrief

| | |
|---|---|
| Wuchsform | Stängelpflanze |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | sehr viel (LED-Panel oder Hochleistungs-LED) |
| Volle Größe | nach etwa 3,5 Tagen |
| Breitet sich aus | Seitentriebe |
| Ableger pro Schnitt | 3 |
| Farbe | röter bei viel Licht |

## Haltung

* Braucht viel Licht für ihre Farbe.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,48–0,58 % pro Schwung (etwa 1 von 174–208 Schwüngen) (Config `features.plantNetCatches`).
* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 0,92–1,1 % pro Schwung (etwa 1 von 90–108 Schwüngen) (Config `features.plantNetCatches`).
* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,98–1,2 % pro Schwung (etwa 1 von 85–102 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Sümpfen: 0,2 % pro Fang (etwa 1 von 489 Fängen), statt des Fischs.
* **Fahrender Händler** (übliche Angebote): 1 für 2 Smaragde.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 3 Ableger pro Schnitt; sie breitet sich auch selbst aus (Seitentriebe).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
