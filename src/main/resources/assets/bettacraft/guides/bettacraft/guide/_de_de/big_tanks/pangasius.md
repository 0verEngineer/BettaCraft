# Pangasius

![Pangasius](../images/tm_pangasius.png)

Der Haiwels: ein unruhiger, silbriger Riese mit dunklem Rücken, hoher, sichelförmiger Rückenflosse und tief gegabelter
Schwanzflosse. Im Heimaquarium wird er etwa einen Meter lang.

**Herkunft:** der Mekong und die großen Flüsse Südostasiens.

## Steckbrief

| | |
|---|---|
| Gruppe | Welse |
| Wissenschaftlicher Name | *Pangasianodon hypophthalmus* |
| Größe | etwa 1 m (2 Blöcke im Spiel) |
| Becken | mindestens 12 × 6 Blöcke, 3 hoch, je 100 Wasserblöcke |
| Temperatur | 22–30 °C |
| Wasser | Süßwasser, robust |
| Wasserchemie | pH 6,0–8,4, TDS 0–700 ppm |
| Schwarm | einzeln oder als Paar |

| Besatz | zählt als 25 Fisch |
| Zucht | vermehrt sich nicht im Aquarium |
| Betta-Becken | nein (frisst sie) |
| Besonderheiten | frisst kleine Fische, Bettas und Garnelen, schwimmt weite Bögen |

## Haltung

* Ein großes Tier: es braucht ein Becken von mindestens 12 × 6 Blöcken und 3 Blöcken Höhe und 100 eigene Wasserblöcke
  ([Größenregel](../big_tanks.md)).
* Es zieht in weiten Bögen durch das ganze Becken und wendet langsam; halte die Beckenmitte frei von hoher Deko.
* Es frisst jedes Futter und ausgewachsen auch kleine Fische, junge Bettas und Garnelen. Es vermehrt sich nicht im Becken.

## Bezug

* **[Großer Kescher](large_net.md)** in Flüssen: 3 % pro Schwung (etwa 1 von 33 Schwüngen), in eine leere Transportwanne (Config `features.bigAnimals`).
* **[Stahlvorfach](steel_leader.md)** (Angeln) in Flüssen: 3,8 % pro Fang (etwa 1 von 27 Fängen), in eine leere Transportwanne (Config `features.bigAnimals`).
* **[Großer Kescher](large_net.md)** in Dschungelgewässern: 1,1 % pro Schwung (etwa 1 von 88 Schwüngen), in eine leere Transportwanne (Config `features.bigAnimals`).
* **[Stahlvorfach](steel_leader.md)** (Angeln) in Dschungelgewässern: 1,4 % pro Fang (etwa 1 von 70 Fängen), in eine leere Transportwanne (Config `features.bigAnimals`).
* **Wild** in Flüssen, in Gruppen von 1–1 (Spawn-Gewicht 3) (Config `features.bigAnimals`).
* **Wild** in Dschungelgewässern, in Gruppen von 1–1 (Spawn-Gewicht 2) (Config `features.bigAnimals`).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
