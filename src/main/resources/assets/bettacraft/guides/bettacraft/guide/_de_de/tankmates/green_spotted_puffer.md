# Grüner Kugelfisch

![Grüner Kugelfisch](../images/tm_green_spotted_puffer.png)

Ein großer, leuchtend grüner Kugelfisch mit runden schwarzen Punkten und weißem Bauch. Er lebt im **Brackwasser** und nie im Süßwasser.

**Herkunft:** die Mangroven und Flussmündungen Südostasiens.

## Steckbrief

| | |
|---|---|
| Gruppe | Kugelfische |
| Wissenschaftlicher Name | *Tetraodon nigroviridis* |
| Größe im Spiel | etwa 9,5 cm (0,8 Blöcke) |
| Temperatur | 24–29 °C |
| Wasser | Brackwasser, auch Meerwasser, normal |
| Wasserchemie | pH 7,2–8,6 |
| Schwarm | einzeln oder als Paar |
| Schwimmt | in der Mitte |
| Besatz | zählt als 2,5 Fisch |
| Zucht | vermehrt sich nicht im Aquarium |
| Betta-Becken | zu groß |
| Besonderheiten | frisst Schnecken, frisst kleine Fische und Garnelen, braucht Schnecken oder hartes Futter für die Zähne, zupft lange Flossen |

## Zucht

Vermehrt sich im Becken praktisch nie.

## Haltung

* **Brackwasser:** 5–30 ppt Salz ([Meerwasser](../saltwater.md): Meersalz und Refraktometer), hart und basisch (pH 7,2–8,6). Im Süßwasser bekommt er einen Salzschock und stirbt.
* **Frisst Schnecken:** etwa eine Schnecke am Tag (`tankmates.behaviour.pufferSnailsPerDay`), zuerst Blasen- und Posthornschnecken; keine großen Apfelschnecken, Rennschnecken selten. Ein Kugelfisch ist das Mittel gegen eine Schneckenplage, und ein kleines Schneckenbecken ernährt ihn.
* **Zähne:** Die schnabelartigen Zähne eines Kugelfischs wachsen ständig nach. Schnecken und [Schalenfutter](../food/food_variety.md) schleifen sie ab; nach 8 Tagen ohne beides (Config `tankmates.behaviour.pufferTeethDays`) sind sie zugewachsen: Der Kugelfisch ist gestresst und verweigert jedes weiche Futter, bis er wieder eine Schnecke oder Schalenfutter bekommt.
* Frisst auch Garnelen und kleine Fische; zupft Flossen. Groß (zählt 2,5 Fische): einzeln halten.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Mangrovensümpfen: 6,5–7,9 % pro Schwung (etwa 1 von 13–15 Schwüngen).
* **Wild** in Mangrovensümpfen, einzeln (Spawn-Gewicht 3) (Config `features.puffers`).
* **Fahrender Händler** (seltene Angebote): 2 für 9 Smaragde; eins von 12 in diesem Angebot.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
