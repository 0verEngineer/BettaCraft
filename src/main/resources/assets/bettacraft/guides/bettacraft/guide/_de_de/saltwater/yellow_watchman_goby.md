# Gelbe Wächtergrundel

![Gelbe Wächtergrundel](../images/sp_yellow_watchman_goby.png)

Die Gelbe Wächtergrundel (*Cryptocentrus cinctus*) aus den Lagunen des westlichen Pazifiks: eine gelbe Grundel mit blauen Punkten, die vor ihrer Höhle auf dem Sand sitzt und Wache hält.

## Steckbrief

| | |
|---|---|
| Gruppe | Grundeln |
| Wissenschaftlicher Name | *Cryptocentrus cinctus* |
| Größe im Spiel | etwa 5 cm (0,42 Blöcke) |
| Temperatur | 22–28 °C |
| Wasser | Meerwasser, normal |
| Wasserchemie | pH 7,8–8,6 |
| Schwarm | einzeln oder als Paar |
| Schwimmt | am Boden |
| Besatz | zählt als 0,6 Fisch |
| Zucht | vermehrt sich nicht im Aquarium |

## Haltung

* Lebt **am Boden**; Sand als Bodengrund passt zu ihr.
* Friedlich: eine gute Gesellschaft für Seepferdchen.
* Sie vermehrt sich nicht im Aquarium.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in warmen Ozeanen (Korallenriffe): 1,7–2 % pro Schwung (etwa 1 von 50–60 Schwüngen).
* **[Kescher](../equipment/tank_net.md)** in lauwarmen Ozeanen: 2,3–2,7 % pro Schwung (etwa 1 von 37–44 Schwüngen).
* **Wild** in warmen Ozeanen (Korallenriffe), einzeln (Spawn-Gewicht 4) (Config `features.saltwater.reefFish`).
* **Wild** in lauwarmen Ozeanen, einzeln (Spawn-Gewicht 3) (Config `features.saltwater.reefFish`).
* **Fahrender Händler** (übliche Angebote): 2 für 3 Smaragde; eins von 4 in diesem Angebot.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
