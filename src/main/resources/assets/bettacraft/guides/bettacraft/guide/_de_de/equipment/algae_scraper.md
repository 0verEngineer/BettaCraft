# Algenschaber

<ItemImage id="bettacraft:algae_scraper" scale="2" />

* **Rechtsklick** auf eine Glasfläche des Beckens: diese Fläche ist sauber.
* **Schleichen + Rechtsklick**: die ganze Seite des Beckens.
* Er nutzt sich für jede gereinigte Fläche ein wenig ab.

Warum die Scheibe grün wird und welche Tiere sie abweiden: [Algen](../aquarium/algae.md).
