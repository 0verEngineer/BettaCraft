# Agassiz-Zwergbuntbarsch

![Agassiz-Zwergbuntbarsch](../images/tm_agassiz_dwarf_cichlid.png)

Das Männchen ist bläulich mit langer Rückenflosse und einer orange und blau gesäumten Spatenschwanzflosse; das Weibchen ist gelb mit dunklem Streifen.

**Herkunft:** das weiche Schwarzwasser des Amazonasbeckens.

## Steckbrief

| | |
|---|---|
| Gruppe | Buntbarsche |
| Wissenschaftlicher Name | *Apistogramma agassizii* |
| Größe im Spiel | etwa 6,5 cm (0,55 Blöcke) |

| Zuchttemperatur | 26–29 °C |
| Wasser | Süßwasser, empfindlich |
| Wasserchemie | pH 5,0–7,2, TDS 0–250 ppm |

| Betta-Becken | mit Vorsicht (großes Becken) |
| Besonderheiten | bewacht seine Brut, revierbildend, 2 Farbformen |

## Farbformen

Farbformen: Wildform, Fire Red. Die Wildform ist dominant, Zuchtformen sind rezessiv: Erst zwei gleiche Allele zeigen die Farbe (Träger sehen wild aus). Von zwei verschiedenen Zuchtformen zeigt sich die zuerst genannte. Wildfänge tragen manchmal eine Zuchtform verdeckt; das Menü zeigt die Gene im Tooltip.

## Zucht

Jedes erwachsene Weibchen besetzt eine eigene **kleine Höhle**: zuerst die [Kokosnussschale](../interior/decor/tubes.md) und die Schieferhöhle, dann die Laichhöhlen, die die Harnischwelse frei lassen. Bei 26–29 °C laicht es dort mit dem Männchen 15–45 Eier, bewacht Eier und Junge allein und **vertreibt jeden anderen Fisch** (Config `tankmates.behaviour.broodDefence`). Ein Weibchen ohne Höhle wird von den Besitzerinnen gejagt; ein Männchen mit einem oder mehreren Weibchen und eine Höhle für jedes. Ohne die Mutter stirbt die Brut.

## Haltung

* Braucht weiches, saures Wasser (Torf, Seemandelbaumblätter, Osmosewasser).
* Männchen sind revierbildend: jedes braucht etwa 4 Wasserblöcke; in einem kleineren Becken werden die überzähligen Männchen gejagt und gebissen.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,17–0,21 % pro Schwung (etwa 1 von 485–574 Schwüngen).
* **Wild** in Dschungelgewässern, einzeln (Spawn-Gewicht 2) (Config `features.tankmates.cichlids`).
* **Fahrender Händler** (übliche Angebote): 2 für 3 Smaragde; eins von 37 in diesem Angebot.
* **[Aquarianer](../getting_started/aquarist.md)** (Meister): 2 für 14 Smaragde; eins von etwa 20 in diesem Angebot (Config `features.tankmates.cichlids`).
* **[Zucht](breeding.md)**: Höhlenbrüter: das Weibchen laicht in einer kleinen Höhle und bewacht die Brut.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
