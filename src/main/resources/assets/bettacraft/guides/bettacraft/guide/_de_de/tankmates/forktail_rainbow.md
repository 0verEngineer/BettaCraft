# Gabelschwanz-Regenbogenfisch

![Gabelschwanz-Regenbogenfisch](../images/tm_forktail_rainbow.png)

Ein kleiner Blauaugen-Regenbogenfisch: blausilbern mit großen Augen, das Männchen mit gelben Flossensäumen und gelben Spitzen an der gegabelten Schwanzflosse.

**Herkunft:** die Regenwaldbäche im Osten Papua-Neuguineas.

## Steckbrief

| | |
|---|---|
| Gruppe | Regenbogenfische |
| Wissenschaftlicher Name | *Pseudomugil furcatus* |
| Größe im Spiel | etwa 5 cm (0,4 Blöcke) |

| Wasserchemie | pH 6,5–8,5, TDS 50–700 ppm |

| Schwimmt | nahe der Oberfläche |
| Besatz | zählt als 0,4 Fisch |
| Zucht | Freilaicher (feinblättrige Pflanzen, Laichmop), 10–30 Junge |
| Betta-Becken | ja |

## Zucht

Bei 25–27 °C streut ein Paar 10–30 Eier in feinfiedrige Pflanzen, Javamoos oder einen **Laichmopp**. Die Eltern und alle anderen Fische fressen die Eier, die sie erreichen; im Laichmopp sind die meisten sicher. Lebendfutter bringt sie schneller in Laichstimmung.

## Haltung

* Schwimmt im Schwarm an der Oberfläche; friedlich, verträgt sich mit einem Betta.
* Laicht jeden Tag ein paar Eier in Moos oder einen Laichmopp.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,27–0,32 % pro Schwung (etwa 1 von 317–375 Schwüngen), 1–4 auf einmal.
* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,27–0,32 % pro Schwung (etwa 1 von 316–374 Schwüngen), 1–4 auf einmal.
* **Wild** in Flüssen, in Gruppen von 3–6 (Spawn-Gewicht 2) (Config `features.tankmates.communityFish`).
* **Wild** in Dschungelgewässern, in Gruppen von 3–6 (Spawn-Gewicht 3) (Config `features.tankmates.communityFish`).
* **Fahrender Händler** (übliche Angebote): 6 für 4 Smaragde; eins von 36 in diesem Angebot.
* **[Zucht](breeding.md)**: Freilaicher (feinblättrige Pflanzen, Laichmop).
