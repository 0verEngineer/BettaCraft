# Krustenanemonen (Zoanthus)

![Krustenanemonen (Zoanthus)](../images/sp_zoanthus.png)

Krustenanemonen (*Zoanthus* sp.) von tropischen Riffen weltweit: Kolonien kleiner Polypen auf kurzen Säulen über einer dünnen Matte, in Grün, Orange und Gold.

## Steckbrief

| | |
|---|---|
| Wuchsform | Polypenrasen (Weichkoralle) |
| Wächst auf | Riffgestein, lebendem Gestein |
| Licht | mittel |
| Strömung | sanft |
| Kalzium | nicht nötig (Weichkoralle) |
| Wasser | Meerwasser |
| Volle Größe | nach etwa 5 Tagen |
| Breitet sich aus | über das Gestein |
| Ableger pro Schnitt | 2 |

## Haltung

* Einfache Weichkoralle: mittleres Licht, sanfte Strömung, kein Kalzium.
* Breitet sich selbst über das Gestein aus; die Polypen **schließen sich kurz**, wenn ein Fisch vorbeischwimmt.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in warmen Ozeanen (Korallenriffe): 0,6–0,72 % pro Schwung (etwa 1 von 139–167 Schwüngen).
* **Schere** an einem wilden Korallenstock in warmen Ozeanen (Korallenriffe): 100 % pro Schnitt (Config `features.wildCorals`).
* **Fahrender Händler** (übliche Angebote): 2 für 4 Smaragde; eins von 4 in diesem Angebot.
* **Ableger**: eine Schere an einer gewachsenen Koralle gibt 2 Ableger pro Schnitt; sie breitet sich auch selbst aus (über das Gestein).
