# Bucephalandra „Snow White“

![Bucephalandra „Snow White“](../images/sp_bucephalandra_snow_white.png)

*Bucephalandra* „Snow White“ (auch als „Biblis“ gehandelt) aus Borneo: Blätter, die bei viel Licht fast weiß werden.

## Steckbrief

| | |
|---|---|
| Wuchsform | Aufsitzerpflanze (Rhizom) |
| Wächst auf | Stein und Holz (auch Deko) |
| Licht | mittel |
| Volle Größe | nach etwa 26 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |
| Farbe | grünlich; weiß bis rosa nur bei viel Licht (ganz unter einem LED-Panel oder einer Hochleistungs-LED) |

## Haltung

* Auf Stein oder Holz; langsam; wächst bei mittlerem Licht.
* Bei normalem Licht grünlich; weiß nur bei viel Licht, ganz erst unter einem [LED-Panel oder einer Hochleistungs-LED](../equipment/light.md), wenn die Lichtstufen an sind.

## Bezug

* **Angeln** in Flüssen: 0,03 % pro Fang (etwa 1 von 3100 Fängen), statt des Fischs.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt; ein abgebautes Rhizomstück teilt sie.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
