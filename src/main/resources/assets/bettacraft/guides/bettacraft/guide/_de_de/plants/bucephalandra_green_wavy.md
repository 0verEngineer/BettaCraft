# Bucephalandra „Green Wavy“

![Bucephalandra „Green Wavy“](../images/sp_bucephalandra_green_wavy.png)

*Bucephalandra* „Green Wavy“ aus den Bächen Borneos: kleine gewellte grüne Blätter an einem Rhizom.

## Steckbrief

| | |
|---|---|
| Wuchsform | Aufsitzerpflanze (Rhizom) |
| Wächst auf | Stein und Holz (auch Deko) |
| Licht | wenig |
| Volle Größe | nach etwa 20 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* Auf Stein oder Holz; langsam, wenig Licht.

## Bezug

* **Angeln** in Dschungelgewässern: 0,56 % pro Fang (etwa 1 von 180 Fängen), statt des Fischs.
* **Angeln** in Flüssen: 0,55 % pro Fang (etwa 1 von 183 Fängen), statt des Fischs.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt; ein abgebautes Rhizomstück teilt sie.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
