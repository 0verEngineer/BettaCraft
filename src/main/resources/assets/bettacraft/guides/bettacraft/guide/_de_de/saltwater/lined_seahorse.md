# Gestreiftes Seepferdchen

![Gestreiftes Seepferdchen](../images/sp_lined_seahorse.png)

Das Gestreifte Seepferdchen (*Hippocampus erectus*) aus dem westlichen Atlantik, von Neuschottland bis Venezuela: das häufigste Seepferdchen aus Nachzucht, dunkel, gelb oder orange, im Spiel etwa 7 cm groß.

## Steckbrief

| | |
|---|---|
| Gruppe | Seepferdchen |
| Wissenschaftlicher Name | *Hippocampus erectus* |
| Größe im Spiel | etwa 7,5 cm (0,62 Blöcke) |
| Temperatur | 18–27 °C |
| Zuchttemperatur | 21–25 °C |
| Wasser | Meerwasser, auch starkes Brackwasser, empfindlich |
| Wasserchemie | pH 7,8–8,6 |
| Schwarm | einzeln oder als Paar |
| Schwimmt | im unteren Wasser |
| Besatz | zählt als 1,5 Fisch |
| Zucht | Bruttasche: das Männchen trägt die Eier, 8–20 Junge |
| Besonderheiten | 3 Farbformen |

## Haltung

* Braucht **Haltepunkte** (Pflanzen, Korallen, Deko, Seegras, Seetang) und **wenig Strömung**.
* Frisst nur **Lebendfutter** (Artemia-Nauplien, Mückenlarven), zweimal am Tag.
* Mag es etwas kühler als die Rifffische. Das Männchen trägt die Eier in seiner **Bruttasche**; siehe [Seepferdchen](seahorses.md).

## Bezug

* **[Kescher](../equipment/tank_net.md)** in warmen Ozeanen (Korallenriffe): 0,62–0,74 % pro Schwung (etwa 1 von 134–160 Schwüngen) (Config `features.seahorses`).
* **[Kescher](../equipment/tank_net.md)** in lauwarmen Ozeanen: 1,5–1,8 % pro Schwung (etwa 1 von 56–67 Schwüngen) (Config `features.seahorses`).
* **Wild** in warmen Ozeanen (Korallenriffe), in Gruppen von 1–1 (Spawn-Gewicht 2) (Config `features.seahorses`).
* **Wild** in lauwarmen Ozeanen, in Gruppen von 1–1 (Spawn-Gewicht 2) (Config `features.seahorses`).
* **Fahrender Händler** (seltene Angebote): 2 für 7 Smaragde; eins von 3 in diesem Angebot (Config `features.seahorses`).
* **[Zucht](seahorses.md)**: Bruttasche: das Männchen trägt die Eier.
