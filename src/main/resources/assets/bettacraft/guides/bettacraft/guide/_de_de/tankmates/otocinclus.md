# Otocinclus (Ohrgitter-Harnischwels)

![Otocinclus (Ohrgitter-Harnischwels)](../images/tm_otocinclus.png)

Ein winziger Saugwels, der Glas und Blätter in kleiner Gruppe sauber weidet.

**Herkunft:** pflanzenreiche Bäche Südamerikas.

## Steckbrief

| | |
|---|---|
| Gruppe | Ohrgitter-Harnischwelse |
| Wissenschaftlicher Name | *Otocinclus vittatus* |
| Größe im Spiel | etwa 4 cm (0,33 Blöcke) |
| Temperatur | 21–27 °C |
| Zuchttemperatur | 22–26 °C |
| Wasser | Süßwasser, empfindlich |
| Wasserchemie | pH 5,8–8,0, TDS 0–500 ppm |
| Schwarm | ab 5 Tieren |
| Schwimmt | an der Scheibe und am Boden |
| Besatz | zählt als 0,3 Fisch |
| Zucht | klebt Eier ans Glas (nach kühlem Wasserwechsel), 6–18 Junge |
| Betta-Becken | zu kühl |
| Besonderheiten | frisst Algen |

## Zucht

Selten, bei 22–26 °C: einzelne Eier an Glas und Blättern (6–18).

## Haltung

* Weidet die Algen am Glas ab und lebt zum Teil davon; ohne Algen braucht er Futtertabletten.
* Bodenfisch: bekommt sinkendes Futter nur zum Teil ab, wenn schnellere Fische da sind - Futtertabletten gehen direkt an ihn.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 1,1–1,3 % pro Schwung (etwa 1 von 79–93 Schwüngen), 1–4 auf einmal.
* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,62–0,73 % pro Schwung (etwa 1 von 137–162 Schwüngen), 1–4 auf einmal.
* **Wild** in Flüssen, in Gruppen von 3–5 (Spawn-Gewicht 2) (Config `features.wildFish`).
* **Wild** in Dschungelgewässern, in Gruppen von 3–5 (Spawn-Gewicht 5) (Config `features.wildFish`).
* **Fahrender Händler** (übliche Angebote): 6 für 3 Smaragde; eins von 16 in diesem Angebot.
* **[Zucht](breeding.md)**: klebt Eier ans Glas (nach kühlem Wasserwechsel).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
