# Bucephalandra „Mini Needle“

![Bucephalandra „Mini Needle“](../images/sp_bucephalandra_mini_needle.png)

*Bucephalandra* „Mini Needle“ aus Borneo: schmale, nadelartige Blätter.

## Steckbrief

| | |
|---|---|
| Wuchsform | Aufsitzerpflanze (Rhizom) |
| Wächst auf | Stein und Holz (auch Deko) |
| Licht | wenig |
| Volle Größe | nach etwa 20 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* Auf Stein oder Holz; langsam, wenig Licht.

## Bezug

* **Angeln** in Dschungelgewässern: 0,48 % pro Fang (etwa 1 von 208 Fängen), statt des Fischs.
* **Angeln** in Flüssen: 0,47 % pro Fang (etwa 1 von 211 Fängen), statt des Fischs.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt; ein abgebautes Rhizomstück teilt sie.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
