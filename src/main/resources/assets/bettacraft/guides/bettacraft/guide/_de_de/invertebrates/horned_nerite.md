# Geweihschnecke

![Geweihschnecke](../images/sp_horned_nerite.png)

Die Geweihschnecke (*Clithon corona*) aus den Brackwasserflüssen Südostasiens: ein kleines dunkles Gehäuse mit kleinen Hörnern.

## Steckbrief

| | |
|---|---|
| Gruppe | Schnecken |
| Größe im Spiel | etwa 1,5 cm (0,13 Blöcke) |
| Temperatur | 20–28 °C |
| Wasser | Süß-, Brack- oder Meerwasser, normal |
| Wasserchemie | pH 6,8–8,6, TDS 100–700 ppm |
| Vermehrung | keine Jungen im Süßwasser |
| Algen | weidet 1,6 Scheiben am Tag ab |
| Klettert an der Scheibe | ja |
| Besatz | 50 zählen als ein Fisch |

## Haltung

* Klein und eine gute Algenfresserin.
* Vermehrt sich im Süßwasser nie.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Mangrovensümpfen: 6,4–7,7 % pro Schwung (etwa 1 von 13–16 Schwüngen), 1–2 auf einmal.
* **[Kescher](../equipment/tank_net.md)** an Stränden: 7,5–9 % pro Schwung (etwa 1 von 11–13 Schwüngen), 1–2 auf einmal.
* **Wild** in Mangrovensümpfen, in Gruppen von 2–5 (Spawn-Gewicht 1) (Config `features.invertebrates.wildSpawns`).
* **Wild** an Stränden, in Gruppen von 2–5 (Spawn-Gewicht 2) (Config `features.invertebrates.wildSpawns`).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
