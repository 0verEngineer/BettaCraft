# Schokoladengurami

![Schokoladengurami](../images/tm_chocolate_gourami.png)

Ein kleiner, scheuer Gurami: schokoladenbraun mit cremefarbenen Binden und gelb gesäumten Flossen; einer der empfindlichsten Aquarienfische.

**Herkunft:** die Torfsümpfe Malaysias, Sumatras und Borneos.

## Steckbrief

| | |
|---|---|
| Gruppe | Fadenfische |
| Wissenschaftlicher Name | *Sphaerichthys osphromenoides* |
| Größe im Spiel | etwa 5,5 cm (0,45 Blöcke) |

| Besonderheiten | atmet Luft (Labyrinthfisch) |

## Zucht

Ein **Maulbrüter**: Bei 27–29 °C laicht ein Weibchen mit einem Männchen und nimmt die Eier ins Maul; nach 3 Tagen (wie bei den Lebendgebärenden, `tankmates.gestationDays`) spuckt sie 10–25 freischwimmende Junge aus. Kein Ablaichkasten nötig, aber die anderen Fische fressen die Jungen: Pflanzen verstecken sie.

## Haltung

* **Labyrinthfisch:** atmet wie ein Betta Luft an der Oberfläche und kommt deshalb mit stillem, sauerstoffarmem Wasser zurecht.
* **Nur sehr weiches, saures Wasser** (pH 4,5–7, TDS bis 200): Torf und Seemandelbaumblätter (siehe [Wasserchemie](../aquarium/water_chemistry.md)); Leitungswasser stresst ihn.
* Eine ruhige Gruppe ab 4; warm (25–30 °C), sehr sauberes Wasser.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 0,3–0,35 % pro Schwung (etwa 1 von 282–334 Schwüngen), 1–4 auf einmal.
* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,13–0,15 % pro Schwung (etwa 1 von 646–765 Schwüngen), 1–4 auf einmal.
* **Wild** in Sümpfen, in Gruppen von 3–4 (Spawn-Gewicht 2) (Config `features.tankmates.gouramis`).
* **Wild** in Dschungelgewässern, in Gruppen von 3–4 (Spawn-Gewicht 2) (Config `features.tankmates.gouramis`).
* **Fahrender Händler** (seltene Angebote): 6 für 7 Smaragde; eins von 14 in diesem Angebot.
* **[Zucht](breeding.md)**: maulbrütend.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
