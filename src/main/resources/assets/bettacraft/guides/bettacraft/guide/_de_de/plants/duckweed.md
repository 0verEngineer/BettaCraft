# Wasserlinse

![Wasserlinse](../images/sp_duckweed.png)

Wasserlinse (*Lemna minor*), auf stillem Wasser fast überall zu Hause: winzige Blätter in kleinen Inseln, die am schnellsten wachsen.

## Steckbrief

| | |
|---|---|
| Wuchsform | Schwimmpflanze |
| Blattgröße | bis 4,1 cm |
| Wachstum | sehr schnell |
| Nimmt Abfall auf | ×0,9 |
| Nestplatz | mäßig |
| Wurzeln | kurz |

## Haltung

* Wächst am schnellsten und nimmt Abfall auf; sie kann die ganze Oberfläche bedecken und das Becken beschatten.
* Kommt ab und zu in einer Flasche Sumpfwasser mit.

## Bezug

* **Angeln** in Sümpfen: 2,7 % pro Fang (etwa 1 von 37 Fängen), statt des Fischs.
* **Angeln** in Mangrovensümpfen: 2,1 % pro Fang (etwa 1 von 48 Fängen), statt des Fischs.
* **Glasflasche** mit Wasser gefüllt in Sümpfen: 15 % pro Flasche, zusätzlich zum Wasser.
* **Ableger**: wächst auf einer beleuchteten Wasseroberfläche und bildet Ableger; mit dem Kescher herausnehmen.
