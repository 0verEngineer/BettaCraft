# Kakadu-Zwergbuntbarsch

![Kakadu-Zwergbuntbarsch](../images/tm_cockatoo_cichlid.png)

Das Männchen trägt einen hohen, zackigen Kamm (den "Kakadu") und eine Leierschwanzflosse mit roten Zeichnungen; das viel kleinere Weibchen ist gelb mit schwarzem Streifen.

**Herkunft:** der obere Amazonas in Peru und Kolumbien.

## Steckbrief

| | |
|---|---|
| Gruppe | Buntbarsche |
| Wissenschaftlicher Name | *Apistogramma cacatuoides* |
| Größe im Spiel | etwa 7 cm (0,6 Blöcke) |
| Temperatur | 22–29 °C |
| Zuchttemperatur | 24–28 °C |
| Wasser | Süßwasser, normal |
| Wasserchemie | pH 5,5–8,0, TDS 0–450 ppm |
| Schwarm | einzeln oder als Paar |
| Schwimmt | im unteren Wasser |
| Besatz | zählt als 0,8 Fisch |
| Zucht | Höhlenbrüter: das Weibchen laicht in einer kleinen Höhle und bewacht die Brut, 15–50 Junge |
| Betta-Becken | mit Vorsicht (großes Becken) |
| Besonderheiten | bewacht seine Brut, revierbildend, 3 Farbformen |

## Farbformen

Farbformen: Wildform, Double Red, Orange Flash. Die Wildform ist dominant, Zuchtformen sind rezessiv: Erst zwei gleiche Allele zeigen die Farbe (Träger sehen wild aus). Von zwei verschiedenen Zuchtformen zeigt sich die zuerst genannte. Wildfänge tragen manchmal eine Zuchtform verdeckt; das Menü zeigt die Gene im Tooltip.

## Zucht

Jedes erwachsene Weibchen besetzt eine eigene **kleine Höhle**: zuerst die [Kokosnussschale](../interior/decor/tubes.md) und die Schieferhöhle, dann die Laichhöhlen, die die Harnischwelse frei lassen. Bei 24–28 °C laicht es dort mit dem Männchen 15–50 Eier, bewacht Eier und Junge allein und **vertreibt jeden anderen Fisch** (Config `tankmates.behaviour.broodDefence`). Ein Weibchen ohne Höhle wird von den Besitzerinnen gejagt; ein Männchen mit einem oder mehreren Weibchen und eine Höhle für jedes. Ohne die Mutter stirbt die Brut.

## Haltung

* Der robusteste Apistogramma: 22–29 °C, auch härteres Wasser.
* Männchen sind revierbildend: jedes braucht etwa 4 Wasserblöcke; in einem kleineren Becken werden die überzähligen Männchen gejagt und gebissen.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,16–0,19 % pro Schwung (etwa 1 von 520–616 Schwüngen).
* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,22–0,26 % pro Schwung (etwa 1 von 388–459 Schwüngen).
* **Wild** in Flüssen, einzeln (Spawn-Gewicht 1) (Config `features.tankmates.cichlids`).
* **Wild** in Dschungelgewässern, einzeln (Spawn-Gewicht 3) (Config `features.tankmates.cichlids`).
* **Fahrender Händler** (übliche Angebote): 2 für 3 Smaragde; eins von 37 in diesem Angebot.
* **[Aquarianer](../getting_started/aquarist.md)** (Meister): 2 für 14 Smaragde; eins von etwa 20 in diesem Angebot (Config `features.tankmates.cichlids`).
* **[Zucht](breeding.md)**: Höhlenbrüter: das Weibchen laicht in einer kleinen Höhle und bewacht die Brut.
