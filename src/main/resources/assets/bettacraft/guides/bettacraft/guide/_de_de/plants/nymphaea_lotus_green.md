# Grüner Tigerlotus

![Grüner Tigerlotus](../images/sp_nymphaea_lotus_green.png)

Der grüne Tigerlotus (*Nymphaea lotus*) aus dem tropischen Afrika: grüne Blätter mit braunen Flecken.

## Steckbrief

| | |
|---|---|
| Wuchsform | Knolle mit Schwimmblättern |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | mittel |
| Volle Größe | nach etwa 6 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* Mittleres Licht, wie der [rote Tigerlotus](red_tiger_lotus.md).
* Ausgewachsen schickt er Schwimmblätter an die Oberfläche; sie beschatten das Becken.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 0,12–0,14 % pro Schwung (etwa 1 von 722–867 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Dschungelgewässern: 0,14 % pro Fang (etwa 1 von 730 Fängen), statt des Fischs.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
