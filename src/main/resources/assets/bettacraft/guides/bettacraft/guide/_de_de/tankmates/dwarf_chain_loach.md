# Zwergschmerle

![Zwergschmerle](../images/tm_dwarf_chain_loach.png)

Eine kleine, gesellige Schmerle, hell mit einer Kette dunkler Glieder an Seite und Rücken; schwimmt öfter im freien Wasser als andere Schmerlen.

**Herkunft:** die Flüsse Thailands und Laos'.

## Steckbrief

| | |
|---|---|
| Gruppe | Schmerlen |
| Wissenschaftlicher Name | *Ambastaia sidthimunki* |
| Größe im Spiel | etwa 5 cm (0,42 Blöcke) |
| Temperatur | 24–29 °C |
| Wasser | Süßwasser, normal |
| Wasserchemie | pH 6,0–8,0, TDS 0–550 ppm |
| Schwarm | ab 6 Tieren |
| Schwimmt | im unteren Wasser |
| Besatz | zählt als 0,4 Fisch |
| Zucht | vermehrt sich nicht im Aquarium |
| Betta-Becken | ja |
| Besonderheiten | frisst Schnecken |

## Zucht

Vermehrt sich im Becken praktisch nie.

## Haltung

* Frisst Schnecken (keine großen Apfelschnecken; `tankmates.behaviour.clownLoachSnailsPerDay`).
* Bodenfisch: bekommt nur einen Teil des sinkenden Futters, solange schnellere Fische da sind - Futtertabletten gehen direkt zu ihm.
* In der Gruppe ab 6; verträgt sich mit einem Betta.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,32–0,38 % pro Schwung (etwa 1 von 260–308 Schwüngen), 1–4 auf einmal.
* **Wild** in Flüssen, in Gruppen von 3–6 (Spawn-Gewicht 2) (Config `features.tankmates.barbsAndLoaches`).
* **Fahrender Händler** (seltene Angebote): 6 für 7 Smaragde; eins von 14 in diesem Angebot.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
