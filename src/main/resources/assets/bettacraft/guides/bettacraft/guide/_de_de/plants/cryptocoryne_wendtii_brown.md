# Cryptocoryne wendtii (braunrot)

![Cryptocoryne wendtii (braunrot)](../images/sp_cryptocoryne_wendtii_brown.png)

*Cryptocoryne wendtii* „Braun“ aus Sri Lanka: gewellte braunrote Blätter.

## Steckbrief

| | |
|---|---|
| Wuchsform | Rosettenpflanze |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | mittel |
| Volle Größe | nach etwa 9 Tagen |
| Breitet sich aus | Ausläufer |
| Ableger pro Schnitt | 1 |
| Farbe | röter bei viel Licht |

## Haltung

* Im Bodengrund; mittleres Licht, bei viel Licht röter.
* Bildet ausgewachsen Ausläufer.

## Bezug

* **Angeln** in Sümpfen und Mangrovensümpfen: 1,2 % pro Fang, statt des Fischs.
* **Glasflasche** mit Wasser gefüllt in Sümpfen: 1,1 % pro Flasche, zusätzlich zum Wasser.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt; sie breitet sich auch selbst aus (Ausläufer).
