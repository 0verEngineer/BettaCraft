# Odessabarbe

![Odessabarbe](../images/tm_odessa_barb.png)

Silbrig-oliv mit dunkel gesäumten Schuppen; das Männchen trägt ein breites scharlachrotes Band an der Seite und schwarz gefleckte Flossen, das Weibchen zwei dunkle Flecken.

**Herkunft:** die Flüsse Zentral-Myanmars.

## Steckbrief

| | |
|---|---|
| Gruppe | Barben |
| Wissenschaftlicher Name | *Pethia padamya* |
| Größe im Spiel | etwa 6 cm (0,48 Blöcke) |
| Temperatur | 18–26 °C |
| Zuchttemperatur | 22–25 °C |
| Wasser | Süßwasser, robust |
| Wasserchemie | pH 6,0–8,4, TDS 0–700 ppm |
| Schwarm | ab 6 Tieren |
| Schwimmt | in der Mitte |
| Besatz | zählt als 0,55 Fisch |
| Zucht | Freilaicher (feinblättrige Pflanzen, Laichmop), 30–80 Junge |
| Betta-Becken | zu kühl |

## Zucht

Bei 22–25 °C streut ein Paar 30–80 Eier in feinfiedrige Pflanzen, Javamoos oder einen **Laichmopp**. Die Eltern und alle anderen Fische fressen die Eier, die sie erreichen; im Laichmopp sind die meisten sicher. Lebendfutter bringt sie schneller in Laichstimmung.

## Haltung

* Kühler als ein Betta-Becken (18–26 °C); friedlich und robust.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,53–0,63 % pro Schwung (etwa 1 von 158–188 Schwüngen), 1–4 auf einmal.
* **Wild** in Flüssen, in Gruppen von 3–6 (Spawn-Gewicht 3) (Config `features.tankmates.barbsAndLoaches`).
* **Fahrender Händler** (übliche Angebote): 6 für 5 Smaragde; eins von 36 in diesem Angebot.
* **[Zucht](breeding.md)**: Freilaicher (feinblättrige Pflanzen, Laichmop).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
