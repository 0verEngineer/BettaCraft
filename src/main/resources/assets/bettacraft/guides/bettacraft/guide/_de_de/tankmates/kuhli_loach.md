# Dornauge

![Dornauge](../images/tm_kuhli_loach.png)

Ein aalartiges, gebändertes Dornauge, das tagsüber versteckt ruht und nachts den Boden absucht.

| | |
|---|---|
| Familie | Schmerlen |
| Wissenschaftlich | *Pangio kuhlii* |
| Größe im Spiel | etwa 7 cm (0,6 Blöcke) |
| Herkunft | Torfsümpfe in Indonesien und Malaysia |
| Temperatur | 24–30 °C |
| Schwarm | ab 5 Tieren |
| Wasser | empfindlich |
| Besatz | 0,4 Fisch |
| Zucht | Freilaicher (feinblättrige Pflanzen, Laichmop), 25–28 °C |

## Zucht

Bei 25–28 °C streut ein Paar 15–50 Eier in feinblättrige Pflanzen, Javamoos oder einen **Laichmop**. Die Eltern und alle anderen Fische fressen erreichbare Eier; im Laichmop sind die meisten sicher. Lebendfutter (Mückenlarven) macht die Fische laichbereiter.

## Haltung

* Bodenfisch: bekommt sinkendes Futter nur zum Teil ab, wenn schnellere Fische da sind - Futtertabletten gehen direkt an ihn.
* Tagsüber meist ruhig, nachts aktiv.

## Beschaffung

Mit dem [Kescher](../invertebrates/catching.md) in Sümpfen und beim fahrenden Händler; danach durch Zucht.
