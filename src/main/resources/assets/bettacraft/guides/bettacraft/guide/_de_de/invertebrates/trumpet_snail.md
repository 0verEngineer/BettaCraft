# Turmdeckelschnecke

![Turmdeckelschnecke](../images/sp_trumpet_snail.png)

Die Turmdeckelschnecke (*Melanoides tuberculata*) aus Afrika und Südasien: ein langes, spitzes Gehäuse.

## Steckbrief

| | |
|---|---|
| Gruppe | Schnecken |
| Größe im Spiel | etwa 2 cm (0,17 Blöcke) |
| Temperatur | 18–32 °C |
| Wasser | Süßwasser, normal |
| Vermehrung | Zwitter: ein Tier genügt, 1–2 Junge |
| Heranwachsen | etwa 3 Tage |
| Algen | weidet 0,1 Scheiben am Tag ab |
| Klettert an der Scheibe | nein |
| Besatz | 50 zählen als ein Fisch |

## Haltung

* **Gräbt sich tagsüber in den Bodengrund** und kommt nachts heraus; sie lockert den Boden.
* Eine Schnecke genügt zur Vermehrung.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 1–2 % pro Schwung, 1–2 auf einmal.
* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 7,3–11 % pro Schwung, 1–2 auf einmal.
* **[Kescher](../equipment/tank_net.md)** in tiefem Höhlenwasser: 26–34 % pro Schwung, 1–2 auf einmal.
* **[Kescher](../equipment/tank_net.md)** in üppigen Höhlen: 20–27 % pro Schwung, 1–2 auf einmal.
* **Schaufel** auf Schlamm in Sümpfen: 8 % pro Versuch, in einen leeren Fischbeutel.
* **Schaufel** auf Schlamm in Mangrovensümpfen: 8 % pro Versuch, in einen leeren Fischbeutel.
* **Wild** in Flüssen, in Gruppen von 2–5 (Spawn-Gewicht 1) (Config `features.wildCritters`).
* **Wild** in Sümpfen, in Gruppen von 2–5 (Spawn-Gewicht 2) (Config `features.wildCritters`).
* **Vermehrung** im Aquarium (ein Tier genügt).
