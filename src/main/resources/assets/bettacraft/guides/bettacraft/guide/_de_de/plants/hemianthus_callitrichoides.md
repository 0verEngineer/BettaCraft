# Hemianthus callitrichoides „Cuba“

![Hemianthus callitrichoides „Cuba“](../images/sp_hemianthus_callitrichoides.png)

Kubanisches Perlkraut (*Hemianthus callitrichoides* „Cuba“) aus Kuba: die kleinsten Blätter aller Aquarienpflanzen, ein hellgrünes Polster über dem Boden.

## Steckbrief

| | |
|---|---|
| Wuchsform | Bodendecker |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | sehr viel (LED-Panel oder Hochleistungs-LED) |
| Volle Größe | nach etwa 4 Tagen |
| Breitet sich aus | Ausläufer |
| Ableger pro Schnitt | 2 |
| CO2 | nötig: ohne CO2 wächst sie mit 40 % Geschwindigkeit |

## Haltung

* Braucht **sehr viel Licht** ([LED-Panel](../equipment/led_panel.md) oder [Hochleistungs-LED](../equipment/high_power_led.md)) und wächst nur mit [CO2](../equipment/co2.md) gut.
* Breitet sich über Ausläufer zu einem dichten Teppich aus; ab und zu zurückschneiden.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,08–0,1 % pro Schwung (etwa 1 von 1042–1250 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Flüssen: 0,03 % pro Fang (etwa 1 von 3100 Fängen), statt des Fischs.
* **Schere** an einem wilden Pflanzenbestand in Sümpfen: 100 % pro Schnitt (Config `features.wildPlants`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 2 Ableger pro Schnitt; sie breitet sich auch selbst aus (Ausläufer).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
