# Hammerkoralle

![Hammerkoralle](../images/sp_hammer_coral.png)

Die Hammerkoralle (*Euphyllia ancora*) aus dem Indopazifik: eine Steinkoralle (LPS), deren lange Tentakel in kleinen Hämmern enden; sie wiegen und pulsieren im Wasser.

## Steckbrief

| | |
|---|---|
| Wuchsform | Äste (Steinkoralle) |
| Wächst auf | Riffgestein, lebendem Gestein |
| Licht | mittel |
| Strömung | mittel |
| Kalzium | baut ein Skelett, verbraucht Kalzium |
| Wasser | Meerwasser |
| Volle Größe | nach etwa 12 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* Baut ein Skelett: braucht **Kalzium** und sauberes Wasser.
* Mittleres Licht und mittlere Strömung.

## Bezug

* **Schere** an einem wilden Korallenstock in warmen Ozeanen (Korallenriffe): 100 % pro Schnitt (Config `features.wildCorals`).
* **Ableger**: eine Schere an einer gewachsenen Koralle gibt 1 Ableger pro Schnitt.
