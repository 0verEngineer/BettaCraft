# Nadelsimse (Eleocharis)

![Nadelsimse (Eleocharis)](../images/sp_eleocharis_acicularis.png)

Nadelsimse (*Eleocharis acicularis*): ein Rasen aus dünnen, aufrechten Nadeln, der sich über Ausläufer ausbreitet.

## Steckbrief

| | |
|---|---|
| Wuchsform | Bodendecker |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | mittel |
| Volle Größe | nach etwa 3,5 Tagen |
| Breitet sich aus | Ausläufer |
| Ableger pro Schnitt | 2 |

## Haltung

* Mittleres Licht; die Nadeln wiegen sich in der Strömung.
* Ein Rasen für den Vordergrund; Garnelen weiden gern darin.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 0,23–0,28 % pro Schwung (etwa 1 von 361–433 Schwüngen) (Config `features.aquaticPlants.netCatches`).
* **Angeln** in Sümpfen: 0,09 % pro Fang (etwa 1 von 1057 Fängen), statt des Fischs.
* **Schere** an einem wilden Pflanzenbestand in Flüssen: 100 % pro Schnitt (Config `features.aquaticPlants.wildPlants`).
* **Schere** an einem wilden Pflanzenbestand in kalten Seen und gefrorenen Flüssen: 100 % pro Schnitt (Config `features.aquaticPlants.wildPlants`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 2 Ableger pro Schnitt; sie breitet sich auch selbst aus (Ausläufer).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
