# Flame-Moos

![Flame-Moos](../images/sp_flame_moss.png)

Flame-Moos (*Taxiphyllum* sp. „Flame“): aufrechte, gedrehte Büschel wie kleine grüne Flammen.

## Steckbrief

| | |
|---|---|
| Wuchsform | Moos |
| Wächst auf | jedem festen Block |
| Licht | wenig |
| Volle Größe | nach etwa 8 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 2 |

## Haltung

* Hält sich an **jedem festen Block**; wenig Licht.
* Wächst eher nach oben als in die Breite: schön auf Holz und vor einem Hintergrund.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,2–0,24 % pro Schwung (etwa 1 von 417–500 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Flüssen: 0,1 % pro Fang (etwa 1 von 1033 Fängen), statt des Fischs.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 2 Ableger pro Schnitt.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
