# Javamoos

![Javamoos](../images/sp_java_moss.png)

Javamoos (*Taxiphyllum barbieri*) aus Südostasien: feine grüne Triebe, die Steine, Holz und den Boden überziehen.

## Steckbrief

| | |
|---|---|
| Wuchsform | Moos |
| Wächst auf | jedem festen Block |
| Licht | wenig |
| Volle Größe | nach etwa 6 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 2 |

## Haltung

* Hält sich an **jedem festen Block**; wenig Licht.
* Ein beliebter Platz für die Eier der Freilaicher und für Garnelen.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,9–1,1 % pro Schwung (etwa 1 von 93–111 Schwüngen) (Config `features.plantNetCatches`).
* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,9–1,1 % pro Schwung (etwa 1 von 93–111 Schwüngen) (Config `features.plantNetCatches`).
* **Schere** an einem Moosblock neben Wasser: 50 % pro Schnitt.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 2 Ableger pro Schnitt.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
