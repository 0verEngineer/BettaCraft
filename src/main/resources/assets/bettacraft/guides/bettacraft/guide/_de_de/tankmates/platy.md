# Platy

![Platy](../images/tm_platy.png)

Ein robuster, friedlicher Lebendgebärender in vielen Farben.

**Herkunft:** Mexiko und Mittelamerika.

## Steckbrief

| | |
|---|---|
| Gruppe | Lebendgebärende |
| Wissenschaftlicher Name | *Xiphophorus maculatus* |
| Größe im Spiel | etwa 5 cm (0,42 Blöcke) |
| Temperatur | 20–27 °C |
| Zuchttemperatur | 22–26 °C |
| Wasser | Süß- oder Brackwasser, robust |
| Wasserchemie | pH 6,8–8,6, TDS 100–800 ppm |
| Schwarm | ab 3 Tieren |
| Schwimmt | in der Mitte |
| Besatz | zählt als 0,5 Fisch |
| Zucht | lebendgebärend, 8–25 Junge |
| Betta-Becken | zu kühl |
| Besonderheiten | 5 Farbformen |

## Farbformen

Farbformen: Wildform, Rot, Sunset, Mickey-Maus, Blau. Die Wildform ist dominant, Zuchtformen sind rezessiv: Erst zwei gleiche Allele zeigen die Farbe (Träger sehen wild aus). Von zwei verschiedenen Zuchtformen zeigt sich die zuerst genannte. Wildfänge tragen manchmal eine Zuchtform verdeckt; das Menü zeigt die Gene im Tooltip.

## Zucht

Bei 22–26 °C wird ein Weibchen mit einem Männchen trächtig und bringt nach 3 Tagen 8–25 fertige Junge zur Welt. Die Erwachsenen fressen Jungfische: Pflanzen verstecken sie, ein **Ablaichkasten** im Becken fängt sie auf.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,89–1,1 % pro Schwung (etwa 1 von 95–113 Schwüngen), 1–4 auf einmal.
* **Wild** in Flüssen, in Gruppen von 3–3 (Spawn-Gewicht 5) (Config `features.wildFish`).
* **Fahrender Händler** (übliche Angebote): 6 für 4 Smaragde; eins von 36 in diesem Angebot.
* **[Zucht](breeding.md)**: lebendgebärend.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
