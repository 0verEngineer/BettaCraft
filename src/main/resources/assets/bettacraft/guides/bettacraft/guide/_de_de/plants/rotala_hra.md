# Rotala „H'ra“

![Rotala „H'ra“](../images/sp_rotala_hra.png)

*Rotala rotundifolia* „H'ra“ aus Vietnam: schmale Blätter, die bei viel Licht orange und rosa werden.

## Steckbrief

| | |
|---|---|
| Wuchsform | Stängelpflanze |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | viel |
| Volle Größe | nach etwa 3 Tagen |
| Breitet sich aus | Seitentriebe |
| Ableger pro Schnitt | 3 |
| Farbe | röter bei viel Licht |
| CO2 | nötig: ohne CO2 wächst sie mit 40 % Geschwindigkeit |

## Haltung

* Schnell; bei viel Licht röter.
* Wächst nur mit [CO2](../equipment/co2.md) richtig.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 0,23–0,28 % pro Schwung (etwa 1 von 361–433 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Sümpfen: 0,1 % pro Fang (etwa 1 von 979 Fängen), statt des Fischs.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 3 Ableger pro Schnitt; sie breitet sich auch selbst aus (Seitentriebe).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
