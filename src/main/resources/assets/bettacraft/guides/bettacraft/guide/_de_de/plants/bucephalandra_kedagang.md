# Bucephalandra „Kedagang“

![Bucephalandra „Kedagang“](../images/sp_bucephalandra_kedagang.png)

*Bucephalandra* „Kedagang“ aus den Bächen Borneos: schmale, dunkelgrüne Blätter mit bläulichem Schimmer.

## Steckbrief

| | |
|---|---|
| Wuchsform | Aufsitzerpflanze (Rhizom) |
| Wächst auf | Stein und Holz (auch Deko) |
| Licht | wenig |
| Volle Größe | nach etwa 22 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* Auf Stein oder Holz; langsam.
* Wenig Licht genügt.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,24–0,29 % pro Schwung (etwa 1 von 347–417 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Flüssen: 0,13 % pro Fang (etwa 1 von 775 Fängen), statt des Fischs.
* **Schere** an einem wilden Pflanzenbestand in Dschungelgewässern: 100 % pro Schnitt (Config `features.wildPlants`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt; ein abgebautes Rhizomstück teilt sie.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
