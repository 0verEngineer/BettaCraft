# Cryptocoryne „Flamingo“

![Cryptocoryne „Flamingo“](../images/sp_cryptocoryne_flamingo.png)

*Cryptocoryne wendtii* „Flamingo“, eine seltene Zuchtform: weißlich rosa Blätter.

## Steckbrief

| | |
|---|---|
| Wuchsform | Rosettenpflanze |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | mittel |
| Volle Größe | nach etwa 14 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |
| Farbe | weißlich rosa, kräftiger bei viel Licht |

## Haltung

* Im Bodengrund; bei viel Licht heller und rosiger.
* Selten: beim fahrenden Händler.

## Bezug

* **Fahrender Händler** (seltene Angebote): 1 für 5 Smaragde.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt.
