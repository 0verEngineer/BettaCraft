# Pygmäen-Panzerwels

Ein winziger Panzerwels, der oft im lockeren Schwarm im freien Wasser schwebt.

| | |
|---|---|
| Familie | Panzerwelse |
| Wissenschaftlich | *Corydoras pygmaeus* |
| Größe im Spiel | etwa 3 cm (0,21 Blöcke) |
| Herkunft | den Rio Madeira (Brasilien) |
| Temperatur | 22–27 °C |
| Schwarm | ab 8 Tieren |
| Wasser | empfindlich |
| Besatz | 0,2 Fisch |
| Zucht | klebt Eier ans Glas (nach kühlem Wasserwechsel), 22–26 °C |

## Zucht

Ein kühler Wasserwechsel löst das Laichen aus: mindestens ein Viertel des Wassers frisch und dadurch um 1,5 °C kühler. Das Weibchen klebt 10–25 Eier ans Glas, an Deko und Blätter. Die anderen Fische fressen sie gerne: mit dem Kescher in eine Tüte nehmen und in einem Becken ohne Erwachsene aufziehen.

## Haltung

* Schießt ab und zu zum Luftholen an die Oberfläche.

## Beschaffung

Mit dem [Kescher](../invertebrates/catching.md) in Dschungelgewässern und beim fahrenden Händler; danach durch Zucht.
