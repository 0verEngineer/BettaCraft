# Pygmäen-Panzerwels

![Pygmäen-Panzerwels](../images/tm_pygmy_cory.png)

Ein winziger Panzerwels, der oft im lockeren Schwarm im freien Wasser schwebt.

**Herkunft:** den Rio Madeira (Brasilien).

## Steckbrief

| | |
|---|---|
| Gruppe | Panzerwelse |
| Wissenschaftlicher Name | *Corydoras pygmaeus* |
| Größe im Spiel | etwa 2,5 cm (0,21 Blöcke) |
| Temperatur | 22–27 °C |
| Zuchttemperatur | 22–26 °C |
| Wasser | Süßwasser, normal |
| Wasserchemie | pH 5,8–8,0, TDS 0–500 ppm |
| Schwarm | ab 8 Tieren |
| Schwimmt | im unteren Wasser |
| Besatz | zählt als 0,2 Fisch |
| Zucht | klebt Eier ans Glas (nach kühlem Wasserwechsel), 10–25 Junge |
| Betta-Becken | zu kühl |
| Besonderheiten | holt Luft an der Oberfläche |

## Zucht

Ein kühler Wasserwechsel löst das Laichen aus: mindestens ein Viertel des Wassers frisch und dadurch um 1,5 °C kühler. Das Weibchen klebt 10–25 Eier ans Glas, an Deko und Blätter. Die anderen Fische fressen sie gerne: mit dem Kescher in eine Tüte nehmen und in einem Becken ohne Erwachsene aufziehen.

## Haltung

* Schießt ab und zu zum Luftholen an die Oberfläche.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,62–0,74 % pro Schwung (etwa 1 von 135–160 Schwüngen), 1–4 auf einmal.
* **Wild** in Dschungelgewässern, in Gruppen von 3–6 (Spawn-Gewicht 7) (Config `features.tankmates.wildSpawns`).
* **Fahrender Händler** (übliche Angebote): 8 für 3 Smaragde; eins von 36 in diesem Angebot.
* **[Zucht](breeding.md)**: klebt Eier ans Glas (nach kühlem Wasserwechsel).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
