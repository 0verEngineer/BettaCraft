# Anubias nana

![Anubias nana](../images/sp_anubias_nana.png)

*Anubias barteri* var. *nana* aus Westafrika (Kamerun): kleine, breite dunkelgrüne Blätter an einem Rhizom.

## Steckbrief

| | |
|---|---|
| Wuchsform | Aufsitzerpflanze (Rhizom) |
| Wächst auf | Stein und Holz (auch Deko) |
| Licht | wenig |
| Volle Größe | nach etwa 25 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* Auf Stein oder Holz; sehr langsam, aber fast unverwüstlich.
* Wenig Licht genügt.

## Bezug

* **Angeln** in Dschungeln und Flüssen: 1,5 % pro Fang, statt des Fischs.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt; ein abgebautes Rhizomstück teilt sie.
