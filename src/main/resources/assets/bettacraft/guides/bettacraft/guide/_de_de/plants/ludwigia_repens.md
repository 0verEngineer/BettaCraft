# Ludwigia repens

![Ludwigia repens](../images/sp_ludwigia_repens.png)

*Ludwigia repens* aus Nord- und Mittelamerika: eine Stängelpflanze mit runden Blättern, grün bis rot.

## Steckbrief

| | |
|---|---|
| Wuchsform | Stängelpflanze |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | mittel |
| Volle Größe | nach etwa 3 Tagen |
| Breitet sich aus | Seitentriebe |
| Ableger pro Schnitt | 3 |
| Farbe | röter bei viel Licht |

## Haltung

* Wächst schnell; mittleres Licht, bei viel Licht röter.

## Bezug

* **Angeln** in Sümpfen: 0,68 % pro Fang (etwa 1 von 147 Fängen), statt des Fischs.
* **Angeln** in Mangrovensümpfen: 0,94 % pro Fang (etwa 1 von 106 Fängen), statt des Fischs.
* **Glasflasche** mit Wasser gefüllt in Sümpfen: 0,85 % pro Flasche, zusätzlich zum Wasser.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 3 Ableger pro Schnitt; sie breitet sich auch selbst aus (Seitentriebe).
