# Kleefarn (Marsilea)

![Kleefarn (Marsilea)](../images/sp_marsilea_hirsuta.png)

Kleefarn (*Marsilea hirsuta*) aus Australien: ein Farn mit kleinen, vierblättrigen Kleeblättern an dünnen Stielen.

## Steckbrief

| | |
|---|---|
| Wuchsform | Bodendecker |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | wenig |
| Volle Größe | nach etwa 6 Tagen |
| Breitet sich aus | Ausläufer |
| Ableger pro Schnitt | 2 |

## Haltung

* Kommt mit **wenig Licht** aus; wächst langsam.
* Der einfachste Bodendecker für ein Becken ohne starkes Licht.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 0,31–0,37 % pro Schwung (etwa 1 von 271–325 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Sümpfen: 0,13 % pro Fang (etwa 1 von 793 Fängen), statt des Fischs.
* **Schere** an einem wilden Pflanzenbestand in Sümpfen: 100 % pro Schnitt (Config `features.wildPlants`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 2 Ableger pro Schnitt; sie breitet sich auch selbst aus (Ausläufer).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
