# Schmetterlingsbuntbarsch

Ein kleiner, bunter Zwergbuntbarsch: goldener Kopf mit schwarzer Augenbinde, ein schwarzer Fleck in der Mitte und blaue Glanzpunkte; das Weibchen hat einen rosa Bauch.

**Herkunft:** die Llanos-Flüsse im Orinoko-Becken in Venezuela und Kolumbien.

## Steckbrief

| | |
|---|---|
| Gruppe | Buntbarsche |
| Wissenschaftlicher Name | *Mikrogeophagus ramirezi* |
| Größe im Spiel | etwa 5,5 cm (0,45 Blöcke) |
| Temperatur | 25–31 °C |
| Zuchttemperatur | 27–30 °C |
| Wasser | Süßwasser, empfindlich |
| Wasserchemie | pH 5,0–7,5, TDS 0–300 ppm |
| Schwarm | einzeln oder als Paar |
| Schwimmt | im unteren Wasser |
| Besatz | zählt als 0,8 Fisch |
| Zucht | Offenbrüter: das Paar laicht auf Stein, Blatt oder Scheibe und bewacht die Brut, 20–60 Junge |
| Betta-Becken | mit Vorsicht (großes Becken) |
| Besonderheiten | bewacht seine Brut, revierbildend, 4 Farbformen |

## Farbformen

Farbformen: Wildform, Gold, Electric Blue, Ballon. Die Wildform ist dominant, Zuchtformen sind rezessiv: Erst zwei gleiche Allele zeigen die Farbe (Träger sehen wild aus). Von zwei verschiedenen Zuchtformen zeigt sich die zuerst genannte. Wildfänge tragen manchmal eine Zuchtform verdeckt; das Menü zeigt die Gene im Tooltip.

## Zucht

Bei 27–30 °C findet sich ein Paar: Das Männchen und das nächste freie Weibchen putzen einen **flachen Stein** (die ebene Oberseite eines Steins oder Schiefers in der unteren Wasserhälfte; sonst eine Grube im Bodengrund) und laichen dort 20–60 Eier. Beide Eltern bleiben an der Brut, fächeln den Eiern Wasser zu und **vertreiben jeden anderen Fisch** (auch Bettas: der Eindringling flieht und wird gebissen, Config `tankmates.behaviour.broodDefence`). Bewachte Eier sind vor den anderen Fischen sicher; sind beide Eltern weg, stirbt die Brut.

## Haltung

* Warm und weich: 25–31 °C passen zum Betta-Becken; mit einem Betta geht es, wenn das Becken groß genug ist und einen eigenen flachen Stein hat (in der Nähe der Brut wird der Betta gebissen).
* Der Ballon ist eine gezüchtete Körperform (kurz und rund); im Spiel liegt er wie die anderen Zuchtformen auf dem Farb-Locus.
* Männchen sind revierbildend: jedes braucht etwa 3 Wasserblöcke; in einem kleineren Becken werden die überzähligen Männchen gejagt und gebissen.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 1,3–1,5 % pro Schwung (etwa 1 von 67–80 Schwüngen).
* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,17–0,2 % pro Schwung (etwa 1 von 506–600 Schwüngen).
* **Wild** in Flüssen, in Gruppen von 1–1 (Spawn-Gewicht 3) (Config `features.cichlids`).
* **Wild** in Dschungelgewässern, in Gruppen von 1–1 (Spawn-Gewicht 2) (Config `features.cichlids`).
* **Fahrender Händler** (übliche Angebote): 2 für 3 Smaragde; eins von 20 in diesem Angebot.
* **[Zucht](breeding.md)**: Offenbrüter: das Paar laicht auf Stein, Blatt oder Scheibe und bewacht die Brut.
