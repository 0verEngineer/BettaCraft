# Rosettenpflanzen und Knollen

Rosettenpflanzen wachsen aus dem **Bodengrund**: ein Büschel Blätter an Stielen. Die Cryptocorynen bilden Ausläufer, die Amazonas-Schwertpflanze wird groß, der Rote Tigerlotus wächst aus einer Knolle und schickt Schwimmblätter an die Oberfläche.
