# Staurogyne repens

![Staurogyne repens](../images/sp_staurogyne_repens.png)

*Staurogyne repens* aus Brasilien: kurze, buschige Triebe mit kleinen Blättern, die niedrig bleiben.

## Steckbrief

| | |
|---|---|
| Wuchsform | Bodendecker |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | mittel |
| Volle Größe | nach etwa 4,5 Tagen |
| Breitet sich aus | Ausläufer |
| Ableger pro Schnitt | 2 |

## Haltung

* Anspruchslos: mittleres Licht, kein CO2 nötig.
* Ein niedriger Bodendecker, der nicht an den Steinen hochwächst.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,27–0,32 % pro Schwung (etwa 1 von 308–369 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Dschungelgewässern: 0,1 % pro Fang (etwa 1 von 973 Fängen), statt des Fischs.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 2 Ableger pro Schnitt; sie breitet sich auch selbst aus (Ausläufer).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
