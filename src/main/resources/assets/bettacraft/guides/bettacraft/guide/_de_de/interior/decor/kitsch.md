# Kitsch

Nicht naturnah, aber lustig – wie die [Mini-Burg](../decor.md):

* **Ruinen-Säule:** eine zerbrochene antike Säule auf ihrem Sockel, daneben eine umgestürzte Trommel und das Kapitell,
  Moos auf den Steinen.
* **Taucherhelm:** ein alter Messinghelm auf seinem Bruststück, mit runden Seitenfenstern. Das Sichtfenster ist offen:
  Kleine Fische schwimmen hinein und hinaus.
* **Schatztruhe:** eine offene Truhe voller Goldmünzen (gelber Beton, kein echtes Gold), die vorne herausquellen.
  Zwischen den Münzen steckt ein [Ausströmerstein](../../equipment/air_stone.md): **Blasen steigen nur, solange eine
  Luftpumpe** am Becken ihn antreibt; er zählt als einer ihrer Ausgänge.
