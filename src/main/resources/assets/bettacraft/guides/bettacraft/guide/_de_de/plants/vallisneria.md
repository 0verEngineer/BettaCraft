# Vallisneria

![Vallisneria](../images/sp_vallisneria.png)

Vallisnerie (*Vallisneria spiralis*), Wasserschraube aus warmen Gewässern weltweit: lange Bänder bis zur Oberfläche und an ihr entlang.

## Steckbrief

| | |
|---|---|
| Wuchsform | Bänder mit Ausläufern |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | mittel |
| Volle Größe | nach etwa 2,5 Tagen |
| Breitet sich aus | Ausläufer |
| Ableger pro Schnitt | 2 |

## Haltung

* Breitet sich mit Ausläufern aus; mittleres Licht.
* Neue Pflanzen (ab 1.14.2) halten ihre Bänder auseinander.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 2,2–2,6 % pro Schwung (etwa 1 von 39–46 Schwüngen) (Config `features.plantNetCatches`).
* **Angeln** in Flüssen: 0,36 % pro Fang (etwa 1 von 274 Fängen), statt des Fischs.
* **Fahrender Händler** (übliche Angebote): 2 für 1 Smaragd.
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 2 Ableger pro Schnitt; sie breitet sich auch selbst aus (Ausläufer).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
