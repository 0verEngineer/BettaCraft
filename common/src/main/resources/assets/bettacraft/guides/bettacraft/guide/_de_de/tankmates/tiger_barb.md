# Sumatrabarbe

![Sumatrabarbe](../images/tm_tiger_barb.png)

Die klassische Barbe: golden mit vier schwarzen Binden, roter Schnauze und roten Flossensäumen; lebhaft und immer in Bewegung.

**Herkunft:** Flüsse und Sümpfe Sumatras und Borneos.

## Steckbrief

| | |
|---|---|
| Gruppe | Barben |
| Wissenschaftlicher Name | *Puntigrus tetrazona* |
| Größe im Spiel | etwa 6 cm (0,5 Blöcke) |
| Temperatur | 20–28 °C |
| Zuchttemperatur | 24–27 °C |
| Wasser | Süßwasser, robust |
| Wasserchemie | pH 6,0–8,4, TDS 0–700 ppm |
| Schwarm | ab 6 Tieren |
| Schwimmt | in der Mitte |
| Besatz | zählt als 0,6 Fisch |
| Zucht | Freilaicher (feinblättrige Pflanzen, Laichmop), 30–80 Junge |
| Betta-Becken | nein (zupft Flossen) |
| Besonderheiten | zupft lange Flossen, 3 Farbformen |

## Farbformen

Farbformen: Wildform, Grün, Albino. Die Wildform ist dominant, Zuchtformen sind rezessiv: Erst zwei gleiche Allele zeigen die Farbe (Träger sehen wild aus). Von zwei verschiedenen Zuchtformen zeigt sich die zuerst genannte. Wildfänge tragen manchmal eine Zuchtform verdeckt; das Menü zeigt die Gene im Tooltip.

## Zucht

Bei 24–27 °C streut ein Paar 30–80 Eier in feinfiedrige Pflanzen, Javamoos oder einen **Laichmopp**. Die Eltern und alle anderen Fische fressen die Eier, die sie erreichen; im Laichmopp sind die meisten sicher. Lebendfutter bringt sie schneller in Laichstimmung.

## Haltung

* **Flossenzupfer:** geht an die langen Flossen von Bettas, Skalaren, Guramis und Guppymännchen (`tankmates.behaviour.finNipping`); im Schwarm unter 6 doppelt so hart. Nicht mit Bettas.
* Robust: 20–28 °C, Leitungswasser.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,49–0,58 % pro Schwung (etwa 1 von 173–205 Schwüngen), 1–4 auf einmal.
* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 0,6–0,71 % pro Schwung (etwa 1 von 141–167 Schwüngen), 1–4 auf einmal.
* **Wild** in Flüssen, in Gruppen von 3–6 (Spawn-Gewicht 3) (Config `features.tankmates.barbsAndLoaches`).
* **Wild** in Sümpfen, in Gruppen von 3–6 (Spawn-Gewicht 3) (Config `features.tankmates.barbsAndLoaches`).
* **Fahrender Händler** (übliche Angebote): 6 für 5 Smaragde; eins von 37 in diesem Angebot.
* **[Aquarianer](../getting_started/aquarist.md)** (Meister): 2 für 14 Smaragde; eins von etwa 20 in diesem Angebot (Config `features.tankmates.barbsAndLoaches`).
* **[Zucht](breeding.md)**: Freilaicher (feinblättrige Pflanzen, Laichmop).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
