# Pfeilkraut (Sagittaria subulata)

![Pfeilkraut (Sagittaria subulata)](../images/sp_sagittaria_subulata.png)

Zwergpfeilkraut (*Sagittaria subulata*) aus Amerika: grasartige, schmale Blätter.

## Steckbrief

| | |
|---|---|
| Wuchsform | Rosettenpflanze |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | wenig |
| Volle Größe | nach etwa 4 Tagen |
| Breitet sich aus | Ausläufer |
| Ableger pro Schnitt | 1 |

## Haltung

* Anspruchslos, wenig Licht.
* Breitet sich schnell über Ausläufer aus.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,24–0,29 % pro Schwung (etwa 1 von 347–417 Schwüngen) (Config `features.aquaticPlants.netCatches`).
* **Angeln** in Flüssen: 0,13 % pro Fang (etwa 1 von 775 Fängen), statt des Fischs.
* **Schere** an einem wilden Pflanzenbestand in Flüssen: 100 % pro Schnitt (Config `features.aquaticPlants.wildPlants`).
* **[Aquarianer](../getting_started/aquarist.md)** (Lehrling): 2 für 2 Smaragde; eins von etwa 8 in diesem Angebot (Config `features.sources.aquaristVillager`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt; sie breitet sich auch selbst aus (Ausläufer).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
