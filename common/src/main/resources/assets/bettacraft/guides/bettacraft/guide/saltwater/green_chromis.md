# Green Chromis

![Green Chromis](../images/sp_green_chromis.png)

The blue-green chromis (*Chromis viridis*) from the Indo-Pacific: small, shimmering green-blue damselfish that hover in shoals above branching corals.

## Profile

| | |
|---|---|
| Group | Damselfish |
| Scientific name | *Chromis viridis* |
| Size in the game | about 4.5 cm (0.38 blocks) |
| Temperature | 24–28 °C |
| Water | sea water, normal |
| Water chemistry | pH 7.8–8.6 |
| Shoal | from 5 fish |
| Swims | in the middle |
| Stocking | counts as 0.5 fish |
| Breeding | Does not breed in a tank |

## Care

* Keep a **shoal of five or more**.
* Fast and busy: not for a seahorse tank.
* It does not breed in a tank.

## Obtaining

* **[Aquarium net](../equipment/tank_net.md)** in warm oceans (coral reefs): 2.4–2.8 % per swing (about 1 in 36–42 swings), 1–4 at a time.
* **[Aquarium net](../equipment/tank_net.md)** in lukewarm oceans: 3.5–4.2 % per swing (about 1 in 24–28 swings), 1–4 at a time.
* **Wild** in warm oceans (coral reefs), in groups of 3–5 (spawn weight 7) (config `features.saltwater.reefFish`).
* **Wild** in lukewarm oceans, in groups of 3–5 (spawn weight 5) (config `features.saltwater.reefFish`).
* **Wandering trader** (usual offers): 6 for 4 emeralds; one of 5 in this offer.

The biomes of biome mods count too ([biome tags](../settings.md)).
