# Weißband-Putzergarnele

![Weißband-Putzergarnele](../images/sp_cleaner_shrimp.png)

Die Weißband-Putzergarnele (*Lysmata amboinensis*) aus dem Indopazifik: rot-weiß gestreift mit langen weißen Fühlern; sie sammelt Parasiten und abgestorbene Haut von den Fischen.

## Steckbrief

| | |
|---|---|
| Gruppe | Garnelen |
| Größe im Spiel | etwa 5,5 cm (0,45 Blöcke) |
| Temperatur | 23–28 °C |
| Wasser | Meerwasser, empfindlich |
| Wasserchemie | pH 7,8–8,6 |
| Vermehrung | vermehrt sich nicht im Aquarium |
| Algen | weidet 0,05 Scheiben am Tag ab |
| Klettert an der Scheibe | ja |
| Besatz | 25 zählen als ein Fisch |

## Haltung

* Die Fische in ihrem Becken **heilen anderthalbmal so schnell**.
* Nur Meerwasser; sie vermehrt sich nicht im Aquarium.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in warmen Ozeanen (Korallenriffe): 6–6,9 % pro Schwung (etwa 1 von 14–17 Schwüngen), 1–3 auf einmal.
* **[Kescher](../equipment/tank_net.md)** in lauwarmen Ozeanen: 1,8–2,1 % pro Schwung (etwa 1 von 47–55 Schwüngen), 1–3 auf einmal.
* **Wild** in warmen Ozeanen (Korallenriffe), in Gruppen von 2–5 (Spawn-Gewicht 1) (Config `features.invertebrates.wildSpawns`).
* **Wild** in lauwarmen Ozeanen, in Gruppen von 2–5 (Spawn-Gewicht 1) (Config `features.invertebrates.wildSpawns`).
* **Fahrender Händler** (seltene Angebote): 1 für 5 Smaragde; eins von 2 in diesem Angebot.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
