# Fettkraut

![Fettkraut](../../images/sp_butterwort.png)

Eine flache Rosette aus klebrigen, gelbgrünen Blättern, die winzige Insekten fangen, mit violetten Blüten auf dünnen Stielen.

## Steckbrief

| | |
|---|---|
| Lebensraum | Sumpf und Ufer (Paludarium) |
| Wuchsform | Rosettenpflanze |
| Wächst auf | Erde, Sand oder Kies auf dem Land (über dem Wasser) |
| Licht | mittel |
| Luftfeuchte | 50–100 % |
| Lufttemperatur | 15–30 °C |
| Volle Größe | nach etwa 8 Tagen |
| Breitet sich aus | nein |
| Schere | 1 Steckling(e) pro Schnitt |
| Gibt Feuchte ab | ja |

## Bezug

* **Schere** an einem wilden Pflanzenbestand auf dem Land von Sümpfen und Mangroven: 100 % pro Schnitt (Config `features.terrariumPlants.wildPlants`).
* **Stecklinge**: eine Schere an einer gewachsenen Pflanze gibt 1 Steckling(e) pro Schnitt.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../../settings.md)).
