# Vriesea (Flammendes Schwert)

![Vriesea (Flammendes Schwert)](../../images/sp_vriesea.png)

Eine Bromelie mit dunkel gebänderten Blättern und einem flachen, roten Blütenschwert. Ihr Kelch hält Wasser für die Kaulquappen der Pfeilgiftfrösche.

## Steckbrief

| | |
|---|---|
| Lebensraum | tropisch-feucht (Regenwald-Terrarium, Land eines Paludariums) |
| Wuchsform | Rosettenpflanze |
| Wächst auf | Erde, Sand oder Kies auf dem Land (über dem Wasser) |
| Licht | mittel |
| Luftfeuchte | 65–100 % |
| Lufttemperatur | 20–30 °C |
| Volle Größe | nach etwa 14 Tagen |
| Breitet sich aus | Ableger rundherum |
| Schere | ein Ableger (eine kleine bewurzelte Pflanze) |
| Gibt Feuchte ab | ja |
| Wasserkelch | nimmt ab halber Größe eine Pfeilgiftfrosch-Kaulquappe auf (Einstellung `features.terrariumPlants.bromeliadTadpoles`) |
| Versteck | Schlangen und Geckos verstecken sich ab halber Größe darin (Einstellung `features.terrariumPlants.hiding`) |

## Bezug

* **Schere** an einem wilden Pflanzenbestand auf dem Boden von Dschungeln: 100 % pro Schnitt (Config `features.terrariumPlants.wildPlants`).
* **Fahrender Händler** (seltene Angebote): 1 für 4 Smaragde; eins von 6 in diesem Angebot.
* **Ableger**: eine Schere an einer gewachsenen Pflanze nimmt einen Ableger ab (eine kleine bewurzelte Pflanze); sie breitet sich auch selbst aus (Ableger rundherum).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../../settings.md)).
