# Echte Aloe

![Echte Aloe](../../images/sp_aloe_vera.png)

Eine Sukkulente mit dicken, graugrünen Blättern mit weichen Zähnen am Rand.

## Steckbrief

| | |
|---|---|
| Lebensraum | trocken und heiß (Wüstenterrarium) |
| Wuchsform | Rosettenpflanze |
| Wächst auf | Erde, Sand oder Kies auf dem Land (über dem Wasser) |
| Licht | viel |
| Luftfeuchte | 10–55 % |
| Lufttemperatur | 20–38 °C |
| Volle Größe | nach etwa 14 Tagen |
| Breitet sich aus | Ableger rundherum |
| Schere | ein Ableger (eine kleine bewurzelte Pflanze) |
| Gibt Feuchte ab | wenig (sie hält ihr Wasser) |
| Versteck | Schlangen und Geckos verstecken sich ab halber Größe darin (Einstellung `features.terrariumPlants.hiding`) |

## Bezug

* **Schere** an einem wilden Pflanzenbestand in Savannen und trockenem Buschland: 100 % pro Schnitt (Config `features.terrariumPlants.wildPlants`).
* **[Aquarianer](../../getting_started/aquarist.md)** (Lehrling): 2 für 2 Smaragde; eins von etwa 8 in diesem Angebot (Config `features.sources.aquaristVillager`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze nimmt einen Ableger ab (eine kleine bewurzelte Pflanze); sie breitet sich auch selbst aus (Ableger rundherum).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../../settings.md)).
