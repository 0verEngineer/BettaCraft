# Pogostemon helferi „Downoi“

![Pogostemon helferi „Downoi“](../images/sp_pogostemon_helferi.png)

*Pogostemon helferi* „Downoi“ aus Thailand und Myanmar: ein niedriger Busch aus gekräuselten, hellgrünen Blättern.

## Steckbrief

| | |
|---|---|
| Wuchsform | Stängelpflanze |
| Wächst auf | Bodengrund (Sand, Kies, Erde, Innenboden) |
| Licht | viel |
| Volle Größe | nach etwa 6 Tagen |
| Breitet sich aus | Seitentriebe |
| Ableger pro Schnitt | 3 |
| CO2 | nötig: ohne CO2 wächst sie mit 40 % Geschwindigkeit |

## Haltung

* Bleibt niedrig: eine Pflanze für den Vordergrund; bildet Seitentriebe.
* Viel Licht; wächst nur mit [CO2](../equipment/co2.md) richtig.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,2–0,24 % pro Schwung (etwa 1 von 417–500 Schwüngen) (Config `features.aquaticPlants.netCatches`).
* **Angeln** in Flüssen: 0,1 % pro Fang (etwa 1 von 1033 Fängen), statt des Fischs.
* **Schere** an einem wilden Pflanzenbestand in Dschungelgewässern: 100 % pro Schnitt (Config `features.aquaticPlants.wildPlants`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 3 Ableger pro Schnitt; sie breitet sich auch selbst aus (Seitentriebe).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
