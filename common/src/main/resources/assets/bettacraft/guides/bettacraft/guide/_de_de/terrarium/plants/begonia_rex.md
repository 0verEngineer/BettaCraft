# Königsbegonie

![Königsbegonie](../../images/sp_begonia_rex.png)

Eine Begonie mit großen, silbrigen Blättern an langen Stielen, einem dunklen Herz und einem farbigen Band.

## Steckbrief

| | |
|---|---|
| Lebensraum | tropisch-feucht (Regenwald-Terrarium, Land eines Paludariums) |
| Wuchsform | Rosettenpflanze |
| Wächst auf | Erde, Sand oder Kies auf dem Land (über dem Wasser) |
| Licht | wenig |
| Luftfeuchte | 65–100 % |
| Lufttemperatur | 20–30 °C |
| Volle Größe | nach etwa 10 Tagen |
| Breitet sich aus | nein |
| Schere | 1 Steckling(e) pro Schnitt |
| Gibt Feuchte ab | ja |
| Versteck | Schlangen und Geckos verstecken sich ab halber Größe darin (Einstellung `features.terrariumPlants.hiding`) |

## Bezug

* **Schere** an einem wilden Pflanzenbestand auf dem Boden von Dschungeln: 100 % pro Schnitt (Config `features.terrariumPlants.wildPlants`).
* **Fahrender Händler** (seltene Angebote): 1 für 4 Smaragde; eins von 6 in diesem Angebot.
* **Stecklinge**: eine Schere an einer gewachsenen Pflanze gibt 1 Steckling(e) pro Schnitt.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../../settings.md)).
