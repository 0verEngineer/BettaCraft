# Bucephalandra „Pink Lady“

![Bucephalandra „Pink Lady“](../images/sp_bucephalandra_pink_lady.png)

*Bucephalandra* „Pink Lady“ aus Borneo: Blätter, die bei viel Licht weiß und rosa werden.

## Steckbrief

| | |
|---|---|
| Wuchsform | Aufsitzerpflanze (Rhizom) |
| Wächst auf | Stein und Holz (auch Deko) |
| Licht | mittel |
| Volle Größe | nach etwa 24 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |
| Farbe | grünlich; weiß bis rosa nur bei viel Licht (ganz unter einem LED-Panel oder einer Hochleistungs-LED) |

## Haltung

* Auf Stein oder Holz; langsam; wächst bei mittlerem Licht.
* Bei normalem Licht grünlich; weiß und rosa nur bei viel Licht, ganz erst unter einem [LED-Panel oder einer Hochleistungs-LED](../equipment/light.md), wenn die Lichtstufen an sind.

## Bezug

* **Angeln** in Flüssen: 0,06 % pro Fang (etwa 1 von 1550 Fängen), statt des Fischs.
* **Schere** an einem wilden Pflanzenbestand in Dschungelgewässern: 100 % pro Schnitt (Config `features.aquaticPlants.wildPlants`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt; ein abgebautes Rhizomstück teilt sie.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
