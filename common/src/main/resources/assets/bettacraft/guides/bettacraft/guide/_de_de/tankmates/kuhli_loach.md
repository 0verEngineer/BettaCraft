# Dornauge

![Dornauge](../images/tm_kuhli_loach.png)

Ein aalartiges, gebändertes Dornauge, das tagsüber versteckt ruht und nachts den Boden absucht.

**Herkunft:** Torfsümpfe in Indonesien und Malaysia.

## Steckbrief

| | |
|---|---|
| Gruppe | Schmerlen |
| Wissenschaftlicher Name | *Pangio kuhlii* |
| Größe im Spiel | etwa 7 cm (0,6 Blöcke) |
| Temperatur | 24–30 °C |
| Zuchttemperatur | 25–28 °C |
| Wasser | Süßwasser, normal |
| Wasserchemie | pH 5,0–7,8, TDS 0–450 ppm |
| Schwarm | ab 5 Tieren |
| Schwimmt | am Boden |
| Besatz | zählt als 0,4 Fisch |
| Zucht | Freilaicher (feinblättrige Pflanzen, Laichmop), 15–50 Junge |
| Betta-Becken | ja |
| Besonderheiten | nachtaktiv |

## Zucht

Bei 25–28 °C streut ein Paar 15–50 Eier in feinblättrige Pflanzen, Javamoos oder einen **Laichmop**. Die Eltern und alle anderen Fische fressen erreichbare Eier; im Laichmop sind die meisten sicher. Lebendfutter (Mückenlarven) macht die Fische laichbereiter.

## Haltung

* Bodenfisch: bekommt sinkendes Futter nur zum Teil ab, wenn schnellere Fische da sind - Futtertabletten gehen direkt an ihn.
* Tagsüber meist ruhig, nachts aktiv.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Sümpfen: 1,2–1,4 % pro Schwung (etwa 1 von 70–83 Schwüngen), 1–4 auf einmal.
* **Wild** in Sümpfen, in Gruppen von 3–5 (Spawn-Gewicht 6) (Config `features.tankmates.wildSpawns`).
* **Fahrender Händler** (übliche Angebote): 6 für 4 Smaragde; eins von 37 in diesem Angebot.
* **[Zucht](breeding.md)**: Freilaicher (feinblättrige Pflanzen, Laichmop).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
