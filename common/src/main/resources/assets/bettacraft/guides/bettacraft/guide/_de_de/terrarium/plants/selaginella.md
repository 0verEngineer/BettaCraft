# Selaginella (Moosfarn)

![Selaginella (Moosfarn)](../../images/sp_selaginella.png)

Ein Moosfarn: ein niedriger Teppich aus fedrigen, farnartigen Trieben für den Boden eines feuchten Terrariums.

## Steckbrief

| | |
|---|---|
| Lebensraum | tropisch-feucht (Regenwald-Terrarium, Land eines Paludariums) |
| Wuchsform | Bodendecker |
| Wächst auf | Erde, Sand oder Kies auf dem Land (über dem Wasser) |
| Licht | wenig |
| Luftfeuchte | 65–100 % |
| Lufttemperatur | 20–30 °C |
| Volle Größe | nach etwa 6 Tagen |
| Breitet sich aus | Ausläufer |
| Schere | teilt das Polster (die Hälfte als Pflanze) |
| Gibt Feuchte ab | ja |

## Bezug

* **Schere** an einem wilden Pflanzenbestand in üppigen Höhlen: 100 % pro Schnitt (Config `features.terrariumPlants.wildPlants`).
* **Teilung**: eine Schere teilt das Polster (die Hälfte als Pflanze); ein abgebautes Stück teilt es auch; sie breitet sich auch selbst aus (Ausläufer).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../../settings.md)).
