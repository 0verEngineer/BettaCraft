# Moskitogras

![Moskitogras](../../images/sp_blue_grama.png)

Ein Gras der Prärie mit gekräuselten Halmen und Samenständen wie kleine Fähnchen; breitet sich mit Ausläufern aus. Landschildkröten fressen es.

## Steckbrief

| | |
|---|---|
| Lebensraum | trocken und heiß (Wüstenterrarium) |
| Wuchsform | Rosettenpflanze |
| Wächst auf | Erde, Sand oder Kies auf dem Land (über dem Wasser) |
| Licht | viel |
| Luftfeuchte | 10–70 % |
| Lufttemperatur | 20–38 °C |
| Volle Größe | nach etwa 5 Tagen |
| Breitet sich aus | Ausläufer |
| Schere | 1 Steckling(e) pro Schnitt |
| Gibt Feuchte ab | wenig (sie hält ihr Wasser) |
| Landschildkröten | fressen sie (Einstellung `features.terrariumPlants.tortoiseGrazing`) |
| Versteck | Schlangen und Geckos verstecken sich ab halber Größe darin (Einstellung `features.terrariumPlants.hiding`) |

## Bezug

* **Schere** an einem wilden Pflanzenbestand in Savannen und trockenem Buschland: 100 % pro Schnitt (Config `features.terrariumPlants.wildPlants`).
* **Stecklinge**: eine Schere an einer gewachsenen Pflanze gibt 1 Steckling(e) pro Schnitt; sie breitet sich auch selbst aus (Ausläufer).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../../settings.md)).
