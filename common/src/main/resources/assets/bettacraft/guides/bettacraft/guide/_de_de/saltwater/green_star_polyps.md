# Grüne Sternpolypen

![Grüne Sternpolypen](../images/sp_green_star_polyps.png)

Grüne Sternpolypen (*Pachyclavularia violacea*) aus dem Indopazifik: eine violette Matte, die das Gestein überzieht, mit grünen, sternförmigen Polypen.

## Steckbrief

| | |
|---|---|
| Wuchsform | Polypenrasen (Weichkoralle) |
| Wächst auf | Riffgestein, lebendem Gestein |
| Licht | mittel |
| Strömung | mittel |
| Kalzium | nicht nötig (Weichkoralle) |
| Wasser | Meerwasser |
| Volle Größe | nach etwa 4 Tagen |
| Breitet sich aus | über das Gestein |
| Ableger pro Schnitt | 2 |

## Haltung

* Einfach und schnell: mittleres Licht und mittlere Strömung, kein Kalzium.
* Wächst schnell über das Gestein; mit der Schere zurückschneiden.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in warmen Ozeanen (Korallenriffe): 0,6–0,72 % pro Schwung (etwa 1 von 139–167 Schwüngen).
* **Schere** an einem wilden Korallenstock in warmen Ozeanen (Korallenriffe): 100 % pro Schnitt (Config `features.corals.wildCorals`).
* **Fahrender Händler** (übliche Angebote): 2 für 4 Smaragde; eins von 4 in diesem Angebot.
* **Ableger**: eine Schere an einer gewachsenen Koralle gibt 2 Ableger pro Schnitt; sie breitet sich auch selbst aus (über das Gestein).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
