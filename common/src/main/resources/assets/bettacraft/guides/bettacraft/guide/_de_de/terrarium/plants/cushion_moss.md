# Kissenmoos

![Kissenmoos](../../images/sp_cushion_moss.png)

Ein hellgrünes Moos, das auf jedem Untergrund zu runden, weichen Polstern wächst.

## Steckbrief

| | |
|---|---|
| Lebensraum | tropisch-feucht (Regenwald-Terrarium, Land eines Paludariums) |
| Wuchsform | Moos |
| Wächst auf | jedem festen Block |
| Licht | wenig |
| Luftfeuchte | 65–100 % |
| Lufttemperatur | 20–30 °C |
| Volle Größe | nach etwa 12 Tagen |
| Breitet sich aus | wächst weiter |
| Schere | teilt das Polster (die Hälfte als Pflanze) |
| Gibt Feuchte ab | ja |

## Bezug

* **Schere** an einem wilden Pflanzenbestand in üppigen Höhlen: 100 % pro Schnitt (Config `features.terrariumPlants.wildPlants`).
* **Schere** an einem wilden Pflanzenbestand auf dem Land von Sümpfen und Mangroven: 100 % pro Schnitt (Config `features.terrariumPlants.wildPlants`).
* **Fahrender Händler** (übliche Angebote): 2 für 2 Smaragde; eins von 9 in diesem Angebot.
* **[Aquarianer](../../getting_started/aquarist.md)** (Lehrling): 2 für 2 Smaragde; eins von etwa 24 in diesem Angebot (Config `features.sources.aquaristVillager`).
* **Teilung**: eine Schere teilt das Polster (die Hälfte als Pflanze); ein abgebautes Stück teilt es auch; sie breitet sich auch selbst aus (wächst weiter).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../../settings.md)).
