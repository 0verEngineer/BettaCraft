# Gelber Segelflossendoktor

![Gelber Segelflossendoktor](../images/sp_yellow_tang.png)

Der Gelbe Segelflossendoktor (*Zebrasoma flavescens*) von den Riffen Hawaiis: ein leuchtend gelber, scheibenförmiger Doktorfisch, der den ganzen Tag Algen vom Gestein weidet.

## Steckbrief

| | |
|---|---|
| Gruppe | Doktorfische |
| Wissenschaftlicher Name | *Zebrasoma flavescens* |
| Größe im Spiel | etwa 9 cm (0,75 Blöcke) |
| Temperatur | 24–28 °C |
| Wasser | Meerwasser, empfindlich |
| Wasserchemie | pH 7,8–8,6 |
| Schwarm | einzeln oder als Paar |
| Schwimmt | in der Mitte |
| Besatz | zählt als 2,5 Fisch |
| Zucht | vermehrt sich nicht im Aquarium |
| Besonderheiten | frisst Algen |

## Haltung

* Ein großer Fisch (zählt als 2,5): er braucht Platz und sauberes Wasser.
* Er **weidet Algen** wie ein Harnischwels und bedrängt Seepferdchen.
* Er vermehrt sich nicht im Aquarium.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in warmen Ozeanen (Korallenriffe): 0,84–1 % pro Schwung (etwa 1 von 99–119 Schwüngen).
* **Wild** in warmen Ozeanen (Korallenriffe), einzeln (Spawn-Gewicht 3) (Config `features.saltwater.reefFish`).
* **Fahrender Händler** (seltene Angebote): 2 für 9 Smaragde; eins von 5 in diesem Angebot.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
