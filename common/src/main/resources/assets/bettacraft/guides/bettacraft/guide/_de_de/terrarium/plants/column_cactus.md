# Säulenkaktus

![Säulenkaktus](../../images/sp_column_cactus.png)

Eine gerippte Säule mit ein oder zwei Armen, die sich nach oben biegen, und wolligen weißen Spitzen.

## Steckbrief

| | |
|---|---|
| Lebensraum | trocken und heiß (Wüstenterrarium) |
| Wuchsform | Kaktus |
| Wächst auf | Erde, Sand oder Kies auf dem Land (über dem Wasser) |
| Licht | viel |
| Luftfeuchte | 10–55 % |
| Lufttemperatur | 20–38 °C |
| Volle Größe | nach etwa 30 Tagen |
| Breitet sich aus | Ableger rundherum |
| Schere | ein Ableger (eine kleine bewurzelte Pflanze) |
| Gibt Feuchte ab | wenig (sie hält ihr Wasser) |

## Bezug

* **Schere** an einem wilden Pflanzenbestand in Wüsten und Tafelbergen: 100 % pro Schnitt (Config `features.terrariumPlants.wildPlants`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze nimmt einen Ableger ab (eine kleine bewurzelte Pflanze); sie breitet sich auch selbst aus (Ableger rundherum).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../../settings.md)).
