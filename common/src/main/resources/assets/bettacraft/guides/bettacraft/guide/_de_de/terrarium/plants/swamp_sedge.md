# Sumpf-Segge

![Sumpf-Segge](../../images/sp_swamp_sedge.png)

Eine Segge des Ufers: ein Büschel schmaler, überhängender Halme, das sich mit Ausläufern ausbreitet. Gut für das Ufer eines Paludariums.

## Steckbrief

| | |
|---|---|
| Lebensraum | Sumpf und Ufer (Paludarium) |
| Wuchsform | Rosettenpflanze |
| Wächst auf | Erde, Sand oder Kies auf dem Land (über dem Wasser) |
| Licht | mittel |
| Luftfeuchte | 50–100 % |
| Lufttemperatur | 15–30 °C |
| Volle Größe | nach etwa 5 Tagen |
| Breitet sich aus | Ausläufer |
| Schere | 1 Steckling(e) pro Schnitt |
| Gibt Feuchte ab | ja |
| Versteck | Schlangen und Geckos verstecken sich ab halber Größe darin (Einstellung `features.terrariumPlants.hiding`) |

## Bezug

* **Schere** an einem wilden Pflanzenbestand auf dem Land von Sümpfen und Mangroven: 100 % pro Schnitt (Config `features.terrariumPlants.wildPlants`).
* **[Aquarianer](../../getting_started/aquarist.md)** (Lehrling): 2 für 2 Smaragde; eins von etwa 8 in diesem Angebot (Config `features.sources.aquaristVillager`).
* **Stecklinge**: eine Schere an einer gewachsenen Pflanze gibt 1 Steckling(e) pro Schnitt; sie breitet sich auch selbst aus (Ausläufer).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../../settings.md)).
