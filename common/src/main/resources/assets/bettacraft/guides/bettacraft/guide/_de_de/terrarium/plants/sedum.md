# Mauerpfeffer

![Mauerpfeffer](../../images/sp_sedum.png)

Ein niedriger Teppich aus kleinen, fleischigen Blättern, die in starkem Licht rot werden, mit winzigen gelben Blüten. Landschildkröten fressen ihn.

## Steckbrief

| | |
|---|---|
| Lebensraum | trocken und heiß (Wüstenterrarium) |
| Wuchsform | Bodendecker |
| Wächst auf | Erde, Sand oder Kies auf dem Land (über dem Wasser) |
| Licht | viel |
| Luftfeuchte | 10–55 % |
| Lufttemperatur | 20–38 °C |
| Volle Größe | nach etwa 6 Tagen |
| Breitet sich aus | Ausläufer |
| Schere | 2 Steckling(e) pro Schnitt |
| Farbe | röter bei viel Licht |
| Gibt Feuchte ab | wenig (sie hält ihr Wasser) |
| Landschildkröten | fressen sie (Einstellung `features.terrariumPlants.tortoiseGrazing`) |

## Bezug

* **Schere** an einem wilden Pflanzenbestand in Wüsten und Tafelbergen: 100 % pro Schnitt (Config `features.terrariumPlants.wildPlants`).
* **Schere** an einem wilden Pflanzenbestand in Savannen und trockenem Buschland: 100 % pro Schnitt (Config `features.terrariumPlants.wildPlants`).
* **Stecklinge**: eine Schere an einer gewachsenen Pflanze gibt 2 Steckling(e) pro Schnitt; sie breitet sich auch selbst aus (Ausläufer).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../../settings.md)).
