# Transportwanne

<ItemImage id="bettacraft:transport_tub" scale="2" />

Trägt **ein großes Tier** mit all seinen Daten. Sie ist schwer: solange eine volle Wanne im Inventar ist, läufst du 35 %
langsamer (`bigAnimalRules.tubSlowness`).

* **Füllen:** der [große Kescher](large_net.md) und das [Stahlvorfach](steel_leader.md) fangen hinein; im Beckenmenü
  legen die Herausnehmen-Knöpfe ein großes Tier hinein; ein großes Tier, das du schon einmal gefangen hast (kein wildes),
  kannst du direkt hineinschöpfen.
* **Ins Becken:** Rechtsklick auf ein Becken, das groß genug ist ([Größenregel](../big_tanks.md)); die Meldung nennt die
  Größe, die das Tier braucht. Die Wanne bringt kein Wasser mit.
* **Freilassen:** Rechtsklick auf offenes Wasser (ein großes Landtier einer anderen Mod wie ein Löwe oder ein Komodowaran: Rechtsklick auf den Boden).
