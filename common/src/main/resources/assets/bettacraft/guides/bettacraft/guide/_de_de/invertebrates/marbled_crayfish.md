# Marmorkrebs

Der Marmorkrebs *Procambarus virginalis* ist ein großer Krebs (etwa 9 cm) mit braun-olivem, dunkel marmoriertem Panzer.
Es gibt **nur Weibchen**: Jedes erwachsene Tier trägt Eier ohne Männchen, und die Jungen sind **Klone** ihrer Mutter
(Jungfernzeugung). Ein Tier genügt für eine ganze Kolonie, und die wächst schnell.

## Steckbrief

| | |
|---|---|
| Gruppe | Krebse |
| Größe im Spiel | etwa 8,5 cm (0,72 Blöcke) |
| Temperatur | 12–30 °C |
| Wasser | Süßwasser, normal |
| Wasserchemie | pH 6,0–8,4, TDS 0–700 ppm |
| Vermehrung | nur Weibchen: jedes erwachsene Tier trägt Eier ohne Männchen, die Jungen sind ihre Klone, 3–6 Junge |
| Heranwachsen | etwa 5 Tage |
| Klettert an der Scheibe | nein |
| Besatz | zählt als 0,75 Fisch |

## Im Becken

* Er verhält sich wie der [Floridakrebs](florida_crayfish.md): Er fängt Kleintiere und Jungfische, zwickt langsame Fische
  am Boden, frisst Pflanzen zurück und gräbt junge Pflanzen aus (siehe dort; dieselben Einstellungen).
* **Er vermehrt sich von allein:** Jedes erwachsene Weibchen trägt immer wieder Eier, 3 bis 6 Junge jedes Mal, nach
  5 Tagen erwachsen. Ein Becken füllt sich schnell: Tiere mit dem [Kescher](../equipment/tank_net.md) oder auf der Seite
  **Kleintiere** im Beckenmenü herausnehmen, oder ihn mit Fischen halten, die die Jungen fressen.
* Sehr robust: 12 bis 30 °C, fast jedes Wasser.
* Keine Farblinien (jedes Tier ist ein Klon); die Marmorierung ist von Tier zu Tier etwas anders.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Flüssen: 0,46 % pro Schwung (etwa 1 von 220 Schwüngen) (Config `features.invertebrates.bigCrayfish`).
* **Wild** in Flüssen, in Gruppen von 2–5 (Spawn-Gewicht 1) (Config `features.invertebrates.bigCrayfish`).
* **Fahrender Händler** (übliche Angebote): 1 für 4 Smaragde (Config `features.invertebrates.bigCrayfish`).
* **Vermehrung** im Aquarium (ein Tier genügt).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
