# Gelbschwanz-Demoiselle

![Gelbschwanz-Demoiselle](../images/sp_yellowtail_damsel.png)

Der Gelbschwanz-Demoiselle (*Chrysiptera parasema*) aus dem westlichen Pazifik: ein leuchtend blauer kleiner Fisch mit gelbem Schwanz, robust und ein guter erster Rifffisch.

## Steckbrief

| | |
|---|---|
| Gruppe | Riffbarsche |
| Wissenschaftlicher Name | *Chrysiptera parasema* |
| Größe im Spiel | etwa 4 cm (0,33 Blöcke) |
| Temperatur | 23–28 °C |
| Wasser | Meerwasser, auch starkes Brackwasser, robust |
| Wasserchemie | pH 7,8–8,6 |
| Schwarm | einzeln oder als Paar |
| Schwimmt | im unteren Wasser |
| Besatz | zählt als 0,45 Fisch |
| Zucht | vermehrt sich nicht im Aquarium |

## Haltung

* **Robust**: verträgt auch starkes Brackwasser ab 20 ‰.
* Er jagt Seepferdchen.
* Er vermehrt sich nicht im Aquarium.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in warmen Ozeanen (Korallenriffe): 1,7–2 % pro Schwung (etwa 1 von 50–59 Schwüngen).
* **[Kescher](../equipment/tank_net.md)** in lauwarmen Ozeanen: 4,2–5,1 % pro Schwung (etwa 1 von 20–24 Schwüngen).
* **Wild** in warmen Ozeanen (Korallenriffe), einzeln (Spawn-Gewicht 5) (Config `features.saltwater.reefFish`).
* **Wild** in lauwarmen Ozeanen, einzeln (Spawn-Gewicht 6) (Config `features.saltwater.reefFish`).
* **Fahrender Händler** (übliche Angebote): 2 für 3 Smaragde; eins von 5 in diesem Angebot.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
