# Fittonie (Silbernetzblatt)

![Fittonie (Silbernetzblatt)](../../images/sp_fittonia.png)

Eine niedrige, buschige Schattenpflanze mit dunklen Blättern und einem Netz heller Adern; in trockener Luft welkt sie schnell.

## Steckbrief

| | |
|---|---|
| Lebensraum | tropisch-feucht (Regenwald-Terrarium, Land eines Paludariums) |
| Wuchsform | Stängelpflanze |
| Wächst auf | Erde, Sand oder Kies auf dem Land (über dem Wasser) |
| Licht | wenig |
| Luftfeuchte | 65–100 % |
| Lufttemperatur | 20–30 °C |
| Volle Größe | nach etwa 5 Tagen |
| Breitet sich aus | Seitentriebe |
| Schere | 3 Steckling(e) pro Schnitt |
| Gibt Feuchte ab | ja |
| Versteck | Schlangen und Geckos verstecken sich ab halber Größe darin (Einstellung `features.terrariumPlants.hiding`) |

## Bezug

* **Schere** an einem wilden Pflanzenbestand auf dem Boden von Dschungeln: 100 % pro Schnitt (Config `features.terrariumPlants.wildPlants`).
* **Fahrender Händler** (übliche Angebote): 2 für 2 Smaragde; eins von 9 in diesem Angebot.
* **[Aquarianer](../../getting_started/aquarist.md)** (Lehrling): 2 für 2 Smaragde; eins von etwa 24 in diesem Angebot (Config `features.sources.aquaristVillager`).
* **Stecklinge**: eine Schere an einer gewachsenen Pflanze gibt 3 Steckling(e) pro Schnitt; sie breitet sich auch selbst aus (Seitentriebe).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../../settings.md)).
