# Rotkopfsalmler

![Rotkopfsalmler](../images/tm_rummy_nose_tetra.png)

Silbern mit leuchtend rotem Kopf und schwarzweiß gestreifter Schwanzflosse; schwimmt im dichten Schwarm.

**Herkunft:** das Schwarzwasser des unteren Amazonas und des Rio Negro.

## Steckbrief

| | |
|---|---|
| Gruppe | Salmler |
| Wissenschaftlicher Name | *Hemigrammus rhodostomus* |
| Größe im Spiel | etwa 5 cm (0,4 Blöcke) |
| Temperatur | 24–29 °C |

| Wasserchemie | pH 5,0–7,8, TDS 0–450 ppm |

| Betta-Becken | ja |

## Zucht

Bei 26–28 °C streut ein Paar 15–40 Eier in feinfiedrige Pflanzen, Javamoos oder einen **Laichmopp**. Die Eltern und alle anderen Fische fressen die Eier, die sie erreichen; im Laichmopp sind die meisten sicher. Lebendfutter bringt sie schneller in Laichstimmung.

## Haltung

* Ein Wasseranzeiger: Er ist empfindlich und sein Rot verblasst bei schlechtem Wasser.
* Ein Schwarm ab 8, weiches Wasser, 24–29 °C: passt ins Betta-Becken.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Dschungelgewässern: 0,52–0,62 % pro Schwung (etwa 1 von 162–191 Schwüngen), 1–4 auf einmal.
* **Wild** in Dschungelgewässern, in Gruppen von 3–6 (Spawn-Gewicht 6) (Config `features.tankmates.communityFish`).
* **Fahrender Händler** (übliche Angebote): 8 für 5 Smaragde; eins von 37 in diesem Angebot.
* **[Zucht](breeding.md)**: Freilaicher (feinblättrige Pflanzen, Laichmop).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
