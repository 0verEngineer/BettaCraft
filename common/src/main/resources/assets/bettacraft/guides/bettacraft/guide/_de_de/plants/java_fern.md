# Javafarn

![Javafarn](../images/sp_java_fern.png)

Javafarn (*Microsorum pteropus*) aus den Bächen Südostasiens: lange, feste Wedel an einem kriechenden Rhizom.

## Steckbrief

| | |
|---|---|
| Wuchsform | Aufsitzerpflanze (Rhizom) |
| Wächst auf | Stein und Holz (auch Deko) |
| Licht | wenig |
| Volle Größe | nach etwa 12 Tagen |
| Breitet sich aus | nein |
| Ableger pro Schnitt | 1 |

## Haltung

* An **Stein oder Holz** binden (auch Deko), nie in den Bodengrund.
* Kommt mit wenig Licht aus; langsam.

## Bezug

* **Angeln** in Dschungelgewässern: 1 % pro Fang (etwa 1 von 97 Fängen), statt des Fischs.
* **Angeln** in Flüssen: 0,97 % pro Fang (etwa 1 von 103 Fängen), statt des Fischs.
* **Schere** an einem wilden Pflanzenbestand in Dschungelgewässern: 100 % pro Schnitt (Config `features.aquaticPlants.wildPlants`).
* **Schere** an einem wilden Pflanzenbestand in Mangrovensümpfen: 100 % pro Schnitt (Config `features.aquaticPlants.wildPlants`).
* **[Aquarianer](../getting_started/aquarist.md)** (Lehrling): 2 für 2 Smaragde; eins von etwa 12 in diesem Angebot (Config `features.sources.aquaristVillager`).
* **Ableger**: eine Schere an einer gewachsenen Pflanze gibt 1 Ableger pro Schnitt; ein abgebautes Rhizomstück teilt sie.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
