# Rote Rennschnecke

![Rote Rennschnecke](../images/sp_red_nerite.png)

Die Rote Rennschnecke (*Vittina waigiensis*, „Red Racer“) aus Indonesien: orange, rot oder tiefrot, manche mit feinen gelben Linien.

## Steckbrief

| | |
|---|---|
| Gruppe | Schnecken |
| Größe im Spiel | etwa 2 cm (0,16 Blöcke) |
| Temperatur | 20–28 °C |
| Wasser | Süß-, Brack- oder Meerwasser, normal |
| Wasserchemie | pH 6,8–8,6, TDS 100–700 ppm |
| Vermehrung | keine Jungen im Süßwasser |
| Algen | weidet 2 Scheiben am Tag ab |
| Klettert an der Scheibe | ja |
| Besatz | 50 zählen als ein Fisch |

## Haltung

* Jede hat ihren **eigenen Farbton** (der Tooltip des Fischbeutels nennt ihn); er lässt sich nicht züchten.
* Vermehrt sich im Süßwasser nie.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in Mangrovensümpfen: 1,4–1,6 % pro Schwung (etwa 1 von 64–70 Schwüngen).
* **Wild** in Mangrovensümpfen, in Gruppen von 2–5 (Spawn-Gewicht 1) (Config `features.invertebrates.wildSpawns`).
* **Fahrender Händler** (seltene Angebote): 2 für 4 Smaragde; eins von 2 in diesem Angebot (Config `features.invertebrates.snailColors`).

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
