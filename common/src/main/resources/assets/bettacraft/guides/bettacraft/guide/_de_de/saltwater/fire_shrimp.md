# Feuergarnele

![Feuergarnele](../images/sp_fire_shrimp.png)

Die Feuergarnele oder Blutrote Putzergarnele (*Lysmata debelius*) aus dem Indopazifik: tiefrot mit weißen Punkten, weißen Beinen und langen weißen Fühlern; scheu, tagsüber versteckt sie sich im Gestein.

## Steckbrief

| | |
|---|---|
| Gruppe | Garnelen |
| Größe im Spiel | etwa 5 cm (0,42 Blöcke) |
| Temperatur | 24–28 °C |
| Wasser | Meerwasser, empfindlich |
| Wasserchemie | pH 7,8–8,6 |
| Vermehrung | vermehrt sich nicht im Aquarium |
| Klettert an der Scheibe | ja |
| Besatz | 25 zählen als ein Fisch |

## Pflege

* Eine Putzergarnele wie die Weißband-Putzergarnele: Die Fische in ihrem Becken **heilen anderthalbmal so schnell**.
* Nur Meerwasser; vermehrt sich nicht im Aquarium.

## Bezug

* **[Kescher](../equipment/tank_net.md)** in warmen Ozeanen (Korallenriffe): 1,8–2,1 % pro Schwung (etwa 1 von 48–56 Schwüngen), 1–3 auf einmal (Config `features.saltwater.moreReefAnimals`).
* **[Kescher](../equipment/tank_net.md)** in lauwarmen Ozeanen: 0,73–0,86 % pro Schwung (etwa 1 von 117–136 Schwüngen), 1–3 auf einmal (Config `features.saltwater.moreReefAnimals`).
* **Wild** in warmen Ozeanen (Korallenriffe), in Gruppen von 2–5 (Spawn-Gewicht 1) (Config `features.saltwater.moreReefAnimals`).
* **Wild** in lauwarmen Ozeanen, in Gruppen von 2–5 (Spawn-Gewicht 1) (Config `features.saltwater.moreReefAnimals`).
* **Fahrender Händler** (seltene Angebote): 1 für 8 Smaragde.

Die Biome von Biome-Mods zählen mit ([Biom-Tags](../settings.md)).
